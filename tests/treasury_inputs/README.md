# 소각 정정 회귀 원문

공개 DART 공시의 저장된 텍스트를 바이트 변경 없이 사용한다. 실제 수량·금액 정답은 정정 본문의 표를 독립 판독해 고정했다.

| 공시 | SHA-256 |
|---|---|
| [한섬 원공시](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260918800133) | `98f8e3d4e7edba87d02ce38b2d6cfa2fd089cbdbe3139119fdb311dc40a68928` |
| [한섬 정정공시](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20261023800327) | `cb5f4fa171f862b0877cb21bc0ababc880d3daf501ed9d02876565b36633dc06` |

정정 후 보통주 소각 예정 수량은 487,988주, 예정 금액은 10,002,991,080원, 예정일은 2026-11-06이다. 실행 완료 근거로 사용하지 않는다.
MCP 회귀의 명부·목록 응답은 이 두 공시만 포함하는 고정 입력이다. 실제 본문 두 건과 합성 관계 반례를 구분하며, 시장 전체 정확도나 운영 배포를 검증하지 않는다.

## 추가 정정 공시·연간 API 표본

`correction_expected.json`은 제품 파서를 읽기 전에 작성한 5사 독립 판독값이다. `correction_<접수번호>.txt`는 해당 DART 공개 본문이며 SHA는 정답 파일에 있다. 조회 주소는 `https://dart.fss.or.kr/dsaf001/main.do?rcpNo=<접수번호>`다. 수량·금액·예정일만 검증하며 회사별 모든 정정 관계가 확정됐음을 뜻하지 않는다.

`celltrion_2025_treasury_api.json`은 저장 원응답 중 `stockTotqySttus`와 `tesstkAcqsDspsSttus`만 보존한 표본이다. 접수번호 `20260316001415`, 기준일 `2025-12-31`. 원 snapshot SHA256은 `5a66783000df0aab2d820b35176e57519fd60668f7cd33cc6413de33668309d4`다. 키·토큰·다른 재무 자료는 포함하지 않는다. 원문에서 독립 확인한 기초12,047,681 + 취득5,284,826 - 처분13,712 - 소각4,970,950 = 기말12,347,845주를 검사한다. 원문 대시와 미기재는 0으로 추정하지 않는다.
