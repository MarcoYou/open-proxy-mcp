# OpenProxy MCP 안내서

> 이 폴더(`wiki/guide/`)는 **사람이 읽는 진입점**입니다. 처음 오셨다면 여기서 시작하세요.
> wiki의 나머지 부분은 상세 도메인 지식·작업 기록으로, 이 안내서가 가리키는 **참고 자료(또는
> AI 에이전트용 지식 베이스)** 로 작동합니다.

## OpenProxy MCP란?

OpenProxy MCP(OPM)는 **한국 상장사의 지배구조·재무 공시를 분석해 주주총회 의결권 행사를 보조하는
시스템**입니다. 전자공시(DART) 등의 반정형 데이터를 정밀하게 정규화하고, 표준 통신 프로토콜
(MCP)을 통해 인공지능(AI) 에이전트가 이를 분석하도록 제공합니다.

> 💡 **쉽게 말하면** — 수백 개 기업의 주총 안건을 사람이 며칠씩 들여다보던 일을, AI가 공시를 자동
> 으로 읽고 법·정책·재무를 따져 "이 안건은 **찬성/반대/검토**"를 근거와 함께 정리해주는 도구입니다.
> (단, 최종 결정은 강요하지 않고 사람의 판단을 돕습니다.)

> 🙋 **이런 분께 유용합니다** — 자산운용사·기관투자자의 **의결권(스튜어드십) 담당자**, 기업
> **지배구조 리서치 애널리스트**, 주총 시즌에 다수 기업을 빠르게 검토해야 하는 분.

## 무엇을, 왜 하나 (의의)

종래에 기관투자자·자산운용사가 의결권을 행사하려면, 담당자가 기업마다 공시를 일일이 찾아 읽고
운용사 지침과 대조하며 후보 경력·재무·법령까지 직접 판단해야 했습니다. 기업 한 곳당 수 시간~수일이
걸려, 정기주총이 몰리는 3~4월에 수백 개 기업을 모두 분석하는 것은 사실상 불가능했습니다.

OPM은 이 과정을 **AI 에이전트가 여러 분석 도구를 동적으로 조합하는 턴키(turn-key) 워크플로우**로
바꿉니다. 핵심은 세 가지입니다:

1. **정밀 정규화** — 표기가 제각각인 반정형 공시(단위·정정·종류주식)를 의미 단위로 정확히 읽어냅니다.
2. **법령 우선 다단계 판단** — 의결권 판단 시 **강행규정(법령) → 운용사 가이드라인 → 기업별 지표**의
   우선순위로 처리하여, 상위가 하위를 무효화합니다. AI가 환각으로 법령과 충돌하는 오판을 막습니다.
3. **판단 보조(결정 강요 아님)** — 점수와 참고 정보를 분리하고 검증 근거(원문 링크)를 붙여, 사람 또는
   AI가 최종 판단을 내리도록 돕습니다.

## 빠른 시작 — 실제로 어떻게 쓰나

OPM은 MCP 서버로 동작하며, AI 에이전트(예: Claude)가 도구를 호출해 사용합니다. 사용자는 자연어로
물어보기만 하면 됩니다.

**예시 — 한 줄 요청:**
> "삼성전자 2026년 정기주총 안건별로 의결권 어떻게 행사할지 분석해줘"

**그러면 AI가 자동으로:**
1. 소집공고에서 **안건 목록**을 읽고 (예: 이사 선임, 재무제표 승인, 배당, 정관 변경…)
2. 안건마다 필요한 데이터를 골라 호출 — 이사 선임이면 **후보 경력·독립성**, 배당이면 **재무·배당 추이**
3. **법 → 운용사 정책 → 재무 지표** 순으로 따져 안건별 **찬성/반대/검토**를 판단
4. 각 판단에 **근거(원문 공시 링크)**를 붙여 정리

**받는 결과(예시 형태):**
> - 제1호 이사 선임 → **검토** (사외이사 후보가 최근 3년 내 거래 관계 있음 — 독립성 확인 필요)
> - 제2호 재무제표 승인 → **찬성** (감사의견 적정, 자본잠식 없음)
> - 제3호 배당 → **찬성** (배당성향 안정적, 과도하지 않음)

수백 개 기업도 같은 방식으로 빠르게 검토할 수 있습니다.

## 핵심 용어 (처음 보는 분께)

| 용어 | 쉬운 설명 |
|---|---|
| **공시** | 상장사가 의무적으로 공개하는 정보 (전자공시시스템 **DART**에 올라옴) |
| **반정형 데이터** | 표·텍스트가 섞여 형식이 회사마다 제각각인 데이터 — 그대로는 기계가 읽기 어려움 |
| **정규화** | 제각각인 표기를 통일된 형식으로 정리하는 것 (예: 단위가 빠진 숫자에 "억원" 붙이기) |
| **의결권 행사** | 주주가 주주총회 안건에 찬성·반대를 투표하는 것 |
| **강행규정** | 반드시 따라야 하는 법 (상법 등) — 회사가 임의로 못 바꿈 |
| **MCP** | AI에게 "도구"를 표준 방식으로 제공하는 규약 (Model Context Protocol) |
| **AI 에이전트** | 도구를 스스로 골라 호출하며 일을 수행하는 AI (예: Claude) |
