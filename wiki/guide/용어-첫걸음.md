# 용어 첫걸음

> OPM 응답에 자주 나오는 말을 한 표에 모았습니다. 더 알고 싶으면 오른쪽 링크(개념 페이지)로.

## 시스템 용어

| 용어 | 쉬운 설명 |
|---|---|
| **공시** | 상장사가 의무적으로 공개하는 정보 (전자공시시스템 **DART**에 올라옴) — [[DART-OpenAPI]] |
| **반정형 데이터** | 표·텍스트가 섞여 형식이 회사마다 제각각인 데이터 — 그대로는 기계가 읽기 어려움 |
| **정규화** | 제각각인 표기를 통일된 형식으로 정리하는 것 (예: 단위가 빠진 숫자에 "억원" 붙이기) — [[단위-표기-규약]] |
| **의결권 행사** | 주주가 주주총회 안건에 찬성·반대를 투표하는 것 — [[의결권]] |
| **강행규정** | 반드시 따라야 하는 법 (상법 등) — 회사가 임의로 못 바꿈 — [[상법-2025-2026-종합]] |
| **MCP** | AI에게 "도구"를 표준 방식으로 제공하는 규약 (Model Context Protocol) |
| **AI 에이전트** | 도구를 스스로 골라 호출하며 일을 수행하는 AI (예: Claude) |

## 공시·식별자

| 용어 | 쉬운 설명 |
|---|---|
| **corp_code** | DART 가 회사마다 붙인 8자리 고유번호. 종목코드(6자리, `stock_code`)와 다르다 — 비상장사도 있다. `company` 도구가 이름으로 찾아 준다 — [[DART-OpenAPI]] |
| **rcept_no** | 공시 한 건의 14자리 접수번호. **앞 8자리가 접수일**(YYYYMMDD) — 「그때 알 수 있던 것」을 가르는 열쇠 — [[시점-제약]] |
| **소집공고 / 주총결과** (`00` / `80`) | 소집공고는 주총 **전**(DART 정기, 접수번호 자릿수 `00`), 주총결과는 주총 **후**(거래소 수시, `80`). 결과를 공고 분석에 되먹이지 않는다 — [[주주총회소집공고]] · [[주주총회결과]] · [[KRX-KIND]] |
| **확정 / 잠정 / 정정** | **확정** = 감사 후 사업보고서 값 · **잠정** = 회사가 먼저 낸 자가 공시(영업(잠정)실적, 소집공고 속 재무제표) · **정정** = 나중에 고쳐 다시 낸 공시(접수번호가 더 뒤). 셋을 한 표에 섞지 않는다 — [[시점-제약]] |

## 재무·밸류

| 용어 | 쉬운 설명 |
|---|---|
| **연결 / 별도** | 연결 = 자회사까지 합친 재무제표(표준) · 별도 = 그 법인 하나만 — [[연결-별도]] |
| **지배주주 귀속 / 전체** | 연결 순이익·자본 중 「우리 회사 주주 몫」 vs 자회사 소수주주 몫까지 합친 값. OPM 은 지배주주 귀속이 기본 — [[연결-별도]] · [[당기순이익]] |
| **FY0 / TTM / MRQ** | FY0 = 마지막 확정 사업연도 · TTM = 최근 4분기 합 · MRQ = 최근 분기말 잔액 — [[PER-PBR]] |
| **시가총액** | 상장주식수 × 종가(보통주). OPM 은 한 곳(`_market_for`)에서만 계산해 모든 도구가 재사용 — [[시가총액]] |
| **PER / PBR** | 시총 ÷ 지배순이익 / 시총 ÷ 지배자본 (주가÷EPS 가 아닌 이유는 페이지에) — [[PER-PBR]] |
| **DPS** | 1주당 배당금(Dividend Per Share). 사업보고서 「배당에 관한 사항」의 보통주 현금배당 — [[배당수익률]] |
| **시가배당률 vs 배당수익률** | 둘 다 배당 ÷ 주가지만 **주가 시점이 다르다** — 시가배당률은 배당 결정 당시(공시값), 배당수익률은 지금(OPM 계산값) — [[배당수익률]] |
| **배당성향** | 배당총액 ÷ 지배주주 귀속 순이익 — [[배당성향]] |

## 주주총회

| 용어 | 쉬운 설명 |
|---|---|
| **보통결의 / 특별결의** | 출석 과반 + 발행주식 1/4 / 출석 2/3 + 발행주식 1/3 — [[주총-결의]] |
| **가결 / 부결 / 찬반율** | 통과 / 미통과 / 안건별 찬성·반대 비율(출석 기준·발행주식 기준 두 벌) — [[주총-결의]] |
| **참석률** | 실제 의결권을 행사한 주식의 비율. 공시에 직접 없어 두 찬성률에서 역산 — [[참석률]] |
| **보수한도 · 소진율** | 이사 보수 상한을 승인하는 안건 · 전기 실지급 ÷ 한도 — [[보수한도]] |
| **위임장 · 프록시 파이트** | 의결권을 남에게 맡기는 서면 · 그 위임장을 모아 벌이는 표 대결 — [[위임장-권유]] · [[프록시-파이트]] |

도구 목록은 [[tools/README]], 시스템 동작은 [[architecture]].
