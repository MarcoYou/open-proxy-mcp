# 아키텍처 — 어떻게 동작하나

> 사람이 이해하기 쉽게 정리한 시스템 설명입니다. 코드 수준 상세는 `docs/ARCHITECTURE.md`,
> 도구별 스키마는 [[tools/README]]를 참조하세요.

## 한눈에 보는 동작

사용자(또는 AI 에이전트)가 "○○기업 의결권 분석"을 요청하면, 시스템은 다음 순서로 동작합니다.

```
 [요청: 회사 + 주총 연도]
        │
        ▼
 ① 도구 오케스트레이션 ── 필요한 분석 도구를 동적으로 선별·병렬 호출 (MCP)
        ▼
 ② 수집 ── 전자공시(DART)에서 공시 수집 (요청 한도 제어)
        ▼
 ③ 정규화 ── 단위 추적 환산 · 정정공시 통합 · 계정코드 앵커 · 안건 분류
        ▼
 ④ 분석 ── 법령 우선 다단계 판단 (법령 → 운용사 정책 → 카테고리 결정)
        ▼
 ⑤ 제공 ── 구조화 데이터 + 사람용 표현 + 검증 근거(원문 링크)를 AI에 제공
```

(옛 구성도 그림·발표 자료는 17-tool 시점이라 storage `decks/opm-wiki-diagrams/` 로 이관 — 260902.)

## 도구 (Tool)

OPM은 담당 영역별로 분리된 도구를 MCP로 제공합니다. AI 에이전트는 안건·후보 유형에 따라
필요한 도구만 골라 병렬로 호출합니다.

도구 목록과 분류(회사 찾기 → 전체시장 스캔 → 주주총회·의결권 → 지분·재무·지배구조 → 주주환원·자본 →
분쟁·거래·리스크 → 근거·참조)는 **[[tools/README]] 「무엇을 알고 싶을 때 무엇을 쓰나」 표가 정본**이라 여기서
반복하지 않는다. 각 도구의 입출력·데이터 출처·파싱 전략은 [[tools/README]]에서 봅니다.

## 핵심 1 — 정규화 정밀화

> 💡 **쉽게 말하면** — 같은 "300억"이라도 어떤 회사는 표 안에 "30,000"(단위는 표 제목에만), 어떤
> 회사는 "300억원"으로 적습니다. 사람이 보면 알지만 기계는 헷갈립니다. OPM은 이런 제각각인 표기를
> **정확한 의미로 통일**해서 읽습니다. 잘못 읽으면 "300억"을 "3만원"으로 착각할 수도 있으니, 이게
> 모든 분석의 기초입니다.

반정형 공시는 표준 API가 없고 회사마다 표기가 달라 통상 방법으로는 정확히 읽기 어렵습니다. OPM은
공시 유형별로 정밀화 수단을 둡니다.

- **단위 추적 환산**: 금액 단위가 셀이 아닌 표 헤더에만 있어도 추적해 환산하고 원본을 병기 (예:
  `630` → `630억원(63,000,000,000원)`)
- **정정공시 통합**: 같은 사안의 정정공시를 다중 신호로 식별해 중복 제거 + 전후 차분 산출
- **계정 코드(ACODE) 앵커**: 표준 서식의 구조적 코드를 기준점으로 삼아 추출 안정성 확보
- **안건 분류**: 주총 안건을 카테고리로 분류하고 상위·하위 관계까지 산출

이 파서들의 정확도는 시장 전체(코스피·코스닥 수백 사)를 AI로 전수조사해 검증·보정합니다.

## 핵심 2 — 의결권 판단의 3단 레이어

> 💡 **쉽게 말하면** — 판단에 "순서"를 둡니다. **법이 정한 건 법대로**(아무리 운용사 정책이나 재무가
> 좋아도 못 바꿈), 법이 안 정한 건 **운용사 성향대로**, 그래도 애매하면 **안건 종류별 기준으로**
> 따집니다. 위 단계가 아래 단계를 덮어쓰기 때문에, AI가 엉뚱하게 법과 어긋나는 판단을 내릴 수 없습니다.

의결권 판단은 단일 룰셋이 아니라 **우선순위가 부여된 다단계 구조**로 동작합니다. 상위 단계가 하위
단계와 AI 판단을 무효화(override)합니다.

```
 [1단계] 법령 정합 (최우선)  ── 강행규정(상법 등)에 해당하면 찬반 고정 또는 검토 표시
        │ 해당 없으면 ↓
 [2단계] 운용사 정책         ── 운용사별 의결권 성향(또는 통합 가이드라인) 적용
        │
 [3단계] 카테고리 결정 로직   ── 안건 종류별 판단 (이사선임은 후보 독립성·결격 평가 입력)
```

- 예: 법으로 방향이 정해진 안건은 운용사 정책·지표와 무관하게 결정이 고정됩니다. → AI가 환각으로
  법령과 충돌하는 오판을 내지 못하게 막는 안전장치입니다.
- 사내이사 연임은 별도로 **재직성과 점수 매트릭스**(ROE·부채비율·주주환원 × 평균·추세)로 평가합니다.
- 점수에 반영하는 항목과 참고 정보를 분리해, 참고 정보가 점수를 왜곡하지 않게 합니다.


## 핵심 3 — 표준 프로토콜(MCP) 제공

분석 결과는 MCP를 통해 AI 에이전트에 제공됩니다. AI가 소비하는 **구조화 데이터**와 사람이 읽는
**표현**을 분리하고, 각 판단에 **원문 접수번호·열람 링크**를 붙여 근거를 추적할 수 있게 합니다.
시스템은 결정을 강요하지 않고 **판단을 보조**합니다.
