# 네이버 금융·뉴스

## 무엇인가

- **네이버 금융**(`finance.naver.com` · `api.finance.naver.com/siseJson.naver`) — 종가·업종 등 시세 페이지. 공식 API 가 아니다.
- **네이버 검색 OpenAPI**(`openapi.naver.com/v1/search/news.json`) — 뉴스 검색. Client ID/Secret 으로 인증하는 공식 API.

## OPM 이 무엇에 쓰나

- **종가 폴백**: 주가는 KRX(Open API·시세 캐시)가 1순위이고, KRX 키가 없거나 응답이 없을 때만 네이버 `siseJson` 으로 특정일 종가를 읽는다. [[배당수익률]](시가배당률 포함)을 자체 계산해야 할 때(공시에 값이 없을 때) 그 분모가 된다.
- **업종 메타**: 회사 카드·밸류업의 업종명(coinfo → sise_group).
- **뉴스**: 이사·감사 후보의 부정 뉴스 검색(`director_news` tool).

시총·주식수 같은 파생지표는 검증된 한 곳(KRX 캐시)을 재사용하고 네이버 값으로 따로 계산하지 않는다.

## 한도 · 예의

| 항목 | 값 |
|---|---|
| 뉴스 API | 25,000회/일 · 분당 100(무료) — 네이버 정책 |
| 금융 페이지 | 비공식 — 웹 스크래핑 규칙과 같다: 배치·병렬 금지, 단계 사이 sleep |
