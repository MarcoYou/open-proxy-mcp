# 연결 · 별도 / 지배주주 귀속 · 전체

## 개념

같은 「순이익」이라도 **어느 재무제표**(연결/별도)의 **누구 몫**(지배주주 귀속/전체)인지에 따라 값이 다르다. 기준을 붙이지 않은 숫자는 비교할 수 없다.

| 축 | 갈래 | 뜻 |
|---|---|---|
| 재무제표 | **연결(CFS)** | 지배회사 + 종속회사를 한 회사처럼 합산. 한국 상장사 공시의 표준 |
| | **별도(OFS)** | 그 법인 하나만. 종속기업 투자는 한 줄(원가·지분법)로 계상. 종속회사가 없어 연결을 작성하지 않는 회사는 별도만 있다 |
| 귀속 | **지배주주 귀속** | 연결 순이익·자본 중 지배회사 주주의 몫 (`ProfitLossAttributableToOwnersOfParent` · 지배기업소유주지분) |
| | **전체(지배+비지배)** | 종속회사 소수주주 몫(비지배지분, NCI)까지 합친 값 |

별도재무제표에는 비지배지분이 없으므로 「전체 = 지배주주 귀속」이다.

## 왜 지배주주 귀속인가

주가·시총·배당은 지배회사 주주의 것이므로 분모도 지배회사 주주의 몫이어야 한다. 전체(NCI 포함)로 나누면 자회사 지분율이 낮은 지주사에서 PER 이 과소, ROE 가 과대해진다. 규정도 일부러 갈라 쓴다 — 자본잠식률은 「자기자본에서 비지배지분 제외」(코스닥 상장관리 해설서 적용기준 ①), 바로 옆 법인세비용차감전계속사업손실 기준은 「비지배지분 포함」. 한쪽 관행을 다른 쪽에 쓰면 안 된다.

## OPM에서의 처리

기본은 **연결 · 지배주주 귀속**. 도구마다 응답에 기준을 실어 보내며, 기준이 다른 값을 한 표에 놓을 땐 기준을 밝힌다.

| 도구 | 재무제표 | 순이익·자본의 귀속 | 기준을 알리는 필드 |
|---|---|---|---|
| `financial_metrics` | 연결 기본(`consolidated=True`), 연결 미작성 회사는 별도 | `net_income_krw` = 지배주주 귀속 · `net_income_total_krw` = 전체(참고) · ROE 분모 = 평균 지배자본 · 자본잠식률의 자기자본 = 지배지분(없으면 자본총계−NCI, 그것도 없으면 자본총계) | `consolidated` · `capital_impairment.basis`(`controlling`/`derived`/`total`) |
| `price_multiple_data` | 연결 | PER 분모 = 지배순이익(FY0·TTM) · PBR 분모 = 지배자본(MRQ) — [[PER-PBR]]. 스케일 항등식(자산=부채+자본)만 총자본 | `multiples_basis` · `pbr_basis` |
| `asset_holdings` | 연결 우선, 없으면 별도 + 경고 | 주석 4필드는 셀마다 XBRL 컨텍스트로 연결/별도를 읽고, 선언이 없으면 기준을 내지 않는다 | `basis` · `basis_conflict` · warnings |
| `financial_notes` | 인자 `basis="연결"` 기본 | 셀마다 연결/별도를 문맥에서 읽는다(열 위치로 짐작하지 않음) | `basis` |
| `provisional_earnings` | 공시 제목 「연결재무제표기준」으로 판정 | 재무형 표준 5행에 지배주주 귀속 순이익 행이 따로 있다(별도는 그 행이 없어 4행) | `consolidated` |
| `dividend_disclosure` · `dividend_data` | 사업보고서 `alotMatter` 「(연결)당기순이익」 | 공시값 그대로 — OPM 이 재계산하지 않는다. 배당성향 = 배당총액 ÷ 그 값 | `net_income_consolidated_mil` |
| `forward_estimates_data` | 벤더 컨센서스(DART 아님) | 벤더가 준 기준을 줄마다 실어 보낸다 | `basis` · `basis_conflict` · `per_basis` |
| `proxy_advise_before_meeting` | 상류 `financial_metrics` 그대로 | 자본잠식 판정 = 연결 지배주주 귀속 | `fin_reference_year` + 상류 `basis` |

- **기준이 다른 숫자를 한 표에 나란히 놓지 않는다** — 연결 순이익과 별도 배당총액으로 배당성향을 내면 뜻이 없다.
- 회계 판단이 들어간 분류·산식은 K-IFRS 정합성 검토를 거친 뒤 코드에 넣는다(CLAUDE.md 작업 원칙 2).
