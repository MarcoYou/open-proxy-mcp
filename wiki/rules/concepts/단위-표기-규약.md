# 단위 표기 규약 (응답 필드 접미어)

## 개념

OPM 응답의 숫자 필드는 **이름 끝에 단위를 붙인다.** 값만 보고 억인지 원인지 %인지 비율인지 짐작하지 않게 하려는 것이다. 공시 원문이 억원·백만원·천원으로 제각각이어도 `_krw` 필드에는 **원 정수**로 환산해 싣고, 원문 단위는 `unit_raw` 같은 별도 필드로 남긴다.

## 접미어 표 (서비스 코드 실측, 260904)

| 접미어 | 뜻 | 예 | 주로 쓰는 곳 |
|---|---|---|---|
| `_krw` | 원(KRW) **정수**. 공시 단위와 무관하게 원으로 환산 | `revenue_krw` · `market_cap_krw` · `eps_fy0_krw` · `dps_krw` | 재무·밸류·자산·배당 도구 전반(600여 곳) |
| `_won` | 원 정수 — `_krw` 와 같은 뜻의 **옛 표기**. 이벤트·계약 도구에 남아 있다 | `contract_amount_won` · `acquisition_amount_won` | `order_contracts` · `corporate_deals` · `dilutive_issuance` · `risk_events` · `screener` |
| `_mil` | **백만원** — DART `alotMatter` 가 백만원 단위로 주는 값을 그대로 | `total_amount_mil` · `net_income_consolidated_mil` | `dividend_disclosure`(→ `shareholder_commitment` 이 ×1,000,000 해 원으로 씀) |
| `_eok` | **억원** — 사람용 렌더 보조 | `rev_eok` · `prev_op_eok` | `director_board`(성과 요약) |
| `_pct` | 퍼센트 값 — `12.3` = 12.3% (0.123 아님). 소수 2자리 | `roe_pct` · `yoy_pct` · `dividend_yield_pct` | 전반 |
| `_ratio` | 배(倍)·비율 — % 아님 | `current_ratio` · `asset_turnover_ratio` · `cfo_to_net_income_ratio` | `financial_metrics` |
| `_cov` · `_multiple` | 배수(시총 대비 등) | `surplus_cov` · `equity_nav_cov` · `gap_multiple` | `asset_holdings` · `forward_estimates_data` |
| `_shares` | 주식수(주) | `acquired_shares` · `before_shares` · `list_shrs`(KRX 명칭 그대로) | `treasury_share` · `dilutive_issuance` · `ownership_structure` |
| `_count` | 건수·명수 | `agenda_count` · `acquisition_count` | 전반 |
| `_days` | 일수 | `cash_conversion_cycle_days` · `age_days` | `financial_metrics` · 캐시 진단 |
| `_date` | 날짜 문자열 — 대부분 `YYYY-MM-DD`(ISO), 원문 그대로 실을 땐 DART 표기(`YYYYMMDD` 등) | `as_of_date` · `agm_date` · `board_date` | 전반 |
| `_dd` | 날짜 `YYYYMMDD` — KRX·스냅샷 DB 컬럼 명칭 | `price_dd` · `snap_dd` | `price_multiple_data` · `forward_estimates_data`(DB) |
| `_ms` | 밀리초 — 진단 필드 | `timings_ms` · `total_wall_ms` | 주요 도구 `data.timings_ms` |
| `ts_ns` | 나노초 epoch — 운영 텔레메트리 이벤트 시각 | `ts_ns` | `usage.py`(사용자 응답이 아니라 서버 내부 표) |

## OPM에서의 처리

- 새 필드를 만들 땐 위 접미어 중 하나를 붙인다. 원 단위 새 필드는 `_won` 이 아니라 **`_krw`** 로.
- `_pct` 와 `_ratio` 를 섞지 않는다 — ROE 는 `_pct`(13.07), 유동비율은 `_ratio`(1.8배) 또는 `_pct`(180) 중 코드가 택한 쪽을 이름이 말해 준다.
- 값의 기준(연결/별도·귀속)은 단위와 별개다 — [[연결-별도]]. 시총의 정의는 [[시가총액]].
- 렌더러(md)는 사람용으로 억·조 단위를 붙여 보이지만, JSON 값은 접미어대로다.
