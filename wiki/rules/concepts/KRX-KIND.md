# KRX KIND

## 무엇인가

한국거래소 기업공시채널(`https://kind.krx.co.kr`). 거래소 수시공시(주주총회결과·현금배당결정·기업가치제고계획·경영권분쟁소송 등)의 원문 HTML 을 보여 준다. 공식 API 가 없어 **HTML 크롤링**으로 읽는다. 같은 문서가 DART 에도 올라오며 접수번호만 다르다 — DART `rcept_no` 의 `80` 을 `00` 으로 바꾸면 KIND `acptno`.

## OPM 이 무엇에 쓰나

- **3순위 폴백.** [[DART-OpenAPI]] → DART 원문(`document.xml`) → DART 웹 viewer 에서 못 풀었을 때만 간다. 병행이 허용되는 것은 **화이트리스트 4종**(주총결과·현금배당결정·기업가치제고계획·소송/경영권분쟁)뿐이고, 소집공고·위임장·5% 대량보유·임원소유·자기주식 이벤트는 KIND 병행 금지.
- 밸류업(기업가치 제고 계획, KIND 세부코드 `0184`)은 KIND 직접 검색을 쓴다([[기업가치제고계획]]).

## 주총결과 (KIND-주총결과)

[[주주총회결과]] 공시의 안건별 찬성·반대·기권 주식수는 KIND 원문 표에 있다. OPM 은 여기서

- [[참석률]] — 발행기준 찬성률 ÷ 행사기준 찬성률로 역산(DART 정형 API 에는 없다)
- [[집중투표]] — 표 형식이 달라 별도 파싱(득표 순위)
- [[감사위원-의결권-제한]] — 3% 룰 적용 안건은 분모가 달라 감사위원 선임 섹션을 따로 읽는다

DART 원문이 먼저이고, 표가 잘렸을 때 KIND 를 폴백으로 쓴다(`shareholder_meeting_results` tool).

## 예의 규칙 (한도를 모른다)

공표된 한도도 공개된 차단 기준도 없다. 「한도가 없다」가 아니라 **「한도를 모른다」**이므로 수치가 아니라 예의로 다룬다:

| 항목 | 값 |
|---|---|
| 간격 | **1.0~2.0초 랜덤**(`_WEB_INTERVAL_RANGE`) — DART 웹과 **같은 규칙·같은 시계**(260810 통일) |
| 배치·병렬 | 금지 |
| 차단 단위 | **IP**(우리 서버). API 키 한도와 달리 하나가 막히면 전원의 폴백 경로가 사라진다 |
| User-Agent | 프로젝트명·연락처 명시 |
