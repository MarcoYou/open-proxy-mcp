# ROE (자기자본이익률)

## 개념

Return on Equity. **순이익 ÷ 자기자본**. 주주가 투자한 자본으로 회사가 얼마의 이익을 냈는지를 보는 핵심 수익성 지표.

## 의미

- 주주 관점의 수익성 — 높을수록 자기자본을 효율적으로 굴림
- [[듀퐁분석]]으로 분해하면 ROE = 순이익률 × 자산회전율 × 재무레버리지. 같은 ROE라도 레버리지로 부풀린 것인지 본업 수익성인지 구분 가능
- 자본잠식(자기자본 음수) 회사는 ROE 의미 없음 — 별도 표시

## OPM에서의 처리

`financial_metrics` tool이 DART 재무제표에서 순이익·자기자본을 받아 산출. 사내이사 재직 성과 매트릭스(`proxy_advise`)의 평균·추세 축으로도 사용 — 재직 기간 ROE 평균과 연도별 추세로 우수/양호/부진/저조 4단계 평가.
