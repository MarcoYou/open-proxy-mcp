# 도메인 지식 (rules)

> OPM이 다루는 한국 상장사 거버넌스·재무의 **배경 지식**입니다. 모르는 용어·공시·법을 여기서 찾습니다.
> 👤 처음이라면 사람용 안내서(`guide/README`)부터. 도구 목록은 `tools/README`.

## 세 가지 영역 — 무엇이 궁금한가

| 궁금한 것 | 어디로 | 내용 |
|---|---|---|
| **용어** (ROE·배당성향·의결권·대주주 등) | [[concepts/README]] | 개념 사전 |
| **공시** (자기주식결정·유상증자·5% 보고 등) | [[disclosures/README]] | 공시 유형 설명 |
| **법** (2025~2026 상법 개정·강행규정) | [[laws/README]] | 법령 자료 |

## 자주 찾는 핵심

- 🔑 **어떤 공시가 어느 검색 코드에 있나** → [[공시유형코드체계]] (모든 공시 검색의 기준)
- 📜 **상법 2025~2026 개정 종합** → [[상법-2025-2026-종합]] (강행규정 + 정관 우회 시나리오)
- 🗳️ **의결권·주주총회 핵심 개념** → [[의결권]] · [[집중투표]] · [[주총-결의]] · [[보수한도]] · [[감사위원-의결권-제한]]
- 📊 **재무 지표** → [[ROE]] · [[ROIC]] · [[배당성향]] · [[듀퐁분석]] · 공통 전제 [[연결-별도]] · [[시가총액]] · [[PER-PBR]]
