## 개요

주주총회 개최 전 주주에게 일시, 장소, 안건을 공지하는 의무 공시. OPM AGM 분석의 기반 원본 문서.

## 소스

- **제출처**: [[DART-OpenAPI]] (`pblntf_ty=E` 기타공시 · `pblntf_detail_ty=E006` 주주총회소집공고 — [[공시유형코드체계]])
- **의무 여부**: 의무
- **공시 주기**: 정기 (정기주총 전 2주 이상 공고)

## 주요 내용

- 주총 일시/장소
- 안건 목록 (이사 선임, 재무제표 승인, [[정관변경]], [[보수한도]] 등)
- 후보자 정보 (경력, 추천인)
- 재무제표 요약
- [[자사주]] 처분/소각 안건

## 전체 문서 구조 (트리)

```
주주총회 소집공고
│
├── 공고 개요 (표지)
│   ├── 회사명, 주총 일시 및 장소
│   └── 공고일 (주총일 2주 이상 전)
│
├── 제1호 의안 ~ 제N호 의안
│   ├── 재무제표 승인 (대차대조표, 손익계산서, 이익잉여금처분계산서)
│   ├── 이사 선임
│   │   └── 후보자별 성명, 생년월일, 주요 경력, 추천인
│   ├── 감사위원 선임 (해당 시)
│   │   └── 후보자별 성명, 경력, 사외이사 여부
│   ├── 이사 보수한도 승인
│   │   └── 이사 총 보수한도액
│   └── 정관 변경 (해당 시)
│       └── 조항별 현행 내용 / 변경 내용
│
└── 참고서류
    ├── 후보자 인적사항 (경력 세부 사항)
    └── 이사회 의결 내역 (후보 추천 근거)
```

검색: DART `list.json` 에 `pblntf_ty="E"` + `pblntf_detail_ty="E006"` 으로 범위를 좁힌 뒤 `report_nm` 에
「주주총회소집공고」 매칭(`"A"` 는 정기공시 코드 — 소집공고가 아니다. 종전 오기 정정 260904).
파싱: OPM은 XML 원문 단독(불완전 시 AI 원문 보정). PDF/OCR 폴백은 open-proxy-ai가 담당한다.

## API 필드 vs 원문 대응

`list.json` 이 주는 것은 **문서 메타데이터**만이다. 안건 번호·안건명·본문 같은 필드는 API 에 없다.

| `list.json` 필드 | 원문 위치 | 실제 의미 | 주의사항 |
|----------|-----------|-----------|----------|
| `pblntf_ty` / `pblntf_detail_ty` | - | 공시 유형 / 상세유형 코드 | `E` / `E006` = 주주총회소집공고 |
| `rcept_no` | 표지 | 접수번호 (14자리) | `document.xml` 원문 조회 키. 자릿수 `00`=DART 정기(소집공고) — `80` 은 거래소 주총결과 |
| `corp_code` / `corp_name` | 표지 | 고유번호 / 회사명 | |
| `corp_cls` | 표지 | 법인 구분 (Y/K/N/E) | |
| `report_nm` | 표지 | 공시 제목 | "주주총회소집공고" 포함 여부 확인, `[기재정정]` 접두 가능 |
| `flr_nm` | 표지 | 제출인 (회사명) | |
| `rcept_dt` | 표지 | 접수일자 | 주총일과 다름 — 주총일은 원문에서 파싱 |
| `rm` | - | 비고 (유/정/연 등) | 정정 여부 |

**주총 일시·장소·안건 목록·후보자 경력은 API 필드로 제공되지 않는다.**
→ `rcept_no` 로 XML 원문(document.xml)을 가져와 파싱한다(OPM은 XML 단독, `get_document_cached`).

## OPM에서의 활용

이 공시를 XML 단독으로 파싱(불완전 시 AI 원문 보정)해 다음을 추출한다:
- 안건 트리 구성
- 재무제표 추출
- 후보자 경력 파싱
- [[정관변경]] 조항 추출
- [[보수한도]] 소진율 산출
- [[자사주]] 안건 파싱
- [[감액배당]] 전제 조건 파싱
- 퇴직금 규정 변경 파싱

파싱 결과는 안건(`agendas`) 배열로 구조화한다 — 필드는 `tools/shareholder_meeting_notice` 참조.

## 관련

[[주주총회결과]]는 주총 후 발생하며, [[시점-제약]]에 따라 결과에서 공고를 참조할 수 있으나 역방향은 금지.
