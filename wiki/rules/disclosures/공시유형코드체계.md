# DART 공시유형 코드체계

DART `list.json` 검색의 2단계 필터 코드 체계.
`pblntf_ty`(대분류 A-J)와 `pblntf_detail_ty`(상세 3자리, 예 `I001`)로 서버단에서 범위를 좁힌다.

- **`pblntf_ty`** = 대분류 1글자 (A-J)
- **`pblntf_detail_ty`** = 상세 코드 (대분류 글자 + 3자리 숫자, 예 `A001`, `I001`)
- 둘 다 list.json 응답 item에는 **들어오지 않음** → 파라미터로 넣어 역으로 좁히는 용도

> **OPM 활용 핵심**: `pblntf_ty="I"`(기타공시 전체)보다 `pblntf_detail_ty="I001"`(주요경영사항)이
> 더 좁다. 배당 검색을 I001로 좁혀 회사당 페이지/호출을 30-40% 줄임 (coverage 손실 0).
> 상세는 아래 [I001 적용] 참조.

## 검증 범위 + 방법론 (중요)

이 매핑은 **업종 다양화 풀에 전체 코드(A-J × 001-012)를 probe한 실증 결과**다 (2026-06-07).
순차(동시성 1) + 호출 사이 sleep로 DART throttle 회피.
스크립트: `scripts/sweep_disclosure_taxonomy.py` (taxonomy 스윕) · `discover_disclosure_codes.py` (6사 상세).

**업종 풀** (코드를 끌어내는 도구 — 어느 기업이냐보다 어떤 코드가 존재하나가 목적):
삼성전자·고려아연·삼성바이오로직스·셀트리온·알테오젠·파두 · KB금융(지주) ·
미래에셋증권(증권) · 롯데리츠(리츠) · 신한카드 · 두산 · 오스템임플란트·한국앤컴퍼니(공개매수).

> ### ⚠️ "빈 슬롯"의 두 가지 의미 — 실증으로 단정 불가
> 실증 probe는 **존재(★)만 증명**한다. 결과 0건은 두 가지가 섞여 있다:
> 1. **DART 코드는 존재하나 풀이 미발생** — 특정 이벤트/주체 필요.
>    예) `D004` 공개매수(적대적 M&A 시), `H00x` 자산유동화(SPC 전용), `B003` 최대주주거래, `C005` 소액공모.
> 2. **코드 자체 미존재(추정)** — 높은 번호(A004+, E007+ 등).
>
> → "전체 DART 카테고리 완전 목록"은 실증만으론 못 만든다 (never-filed 코드는 안 보임).
> 사업회사 유니버스가 **실제로 만나는** 코드는 아래에 다 있음 + governance 핵심 `D004`까지 보강.

**업종별 경계 발견:**
- **금융지주(KB)** → 새 코드 0. 금융 특유 공시도 기존 코드 변종 (C002 일괄신고=회사채 / B001 코코본드 / I001 주식소각).
- **증권사(미래에셋)** → `C003` 파생결합증권(ELS/DLS) 16,000+건 — 증권사 전용.
- **리츠(롯데리츠)** → `G002` 집합투자증권 · `B002`/`J005` 리츠 주요사항 · `D005` 거래계획 사전공시.
- **공개매수 당사자(오스템·한국앤컴퍼니)** → `D004` 공개매수신고서/설명서/결과보고서.
- **`H` 자산유동화** → 카드사(신한카드)에서도 0. ABS는 유동화전문회사(SPC)가 자기 corp_code로 발행 →
  사업회사 corp_code엔 구조적으로 안 잡힘. OPM 유니버스 밖.

## 상세코드 (pblntf_detail_ty) 매핑

`6사` 열 = 6개 검증 회사 중 해당 코드 공시를 제출한 회사 수.

## I001 적용 (배당 검색 최적화)

배당결정·배당 주주명부폐쇄 공시는 전부 `I001` 하위.
기존 `pblntf_ty="I"`(기타공시 전체, 회사당 3-5페이지) 대신 `pblntf_detail_ty="I001"`(2-3페이지)로 전환.

검증: 6년치 6사 `I 전체` vs `I001` 결과 `rcept_no` **차집합 0건** — 같은 배당 공시 전부 포함, 호출만 감소.

```python
# dividend._search_dividend_filings 내부 검색
items, notices, error = await fetch_filings_for_title_scan(
    corp_code=corp_code, bgn_de=..., end_de=...,
    pblntf_tys="",
    pblntf_detail_ty="I001",   # I 전체 대신 주요경영사항만
    keyword_label="배당결정+명부폐쇄",
)
```

같은 패턴으로 다른 tool도 좁힐 여지: 주총(I001 주총소집결의·결과), 경영권분쟁소송(I001 소송등의제기), 지배구조보고서(I001).

**proxy_contest 보강 후보**: `D004`(공개매수)는 적대적 M&A 직접 신호인데 현재 미반영.
`D003`(위임장권유) + `D004`(공개매수) + `I001`(경영권분쟁소송) + `D001`(5% 변동)을 묶으면 경영권 분쟁
신호 커버리지가 넓어진다. `D005`(거래계획 사전공시)는 내부자 매매 의도 신호로 활용 가능.
