# opm-stats-artifact

OPM(open-proxy-mcp) 외부 사용자 통계를 **LinkedIn 포스트에 캡처해 올리기 좋은 16:9 슬라이드**
(PPT 1장 비율, **라이트 테마**)로 만들어 Artifact로 게시한다. 핵심 메트릭 카드 4개 +
**일별 단일사용자(막대) × 인당요청(선) 콤보 차트**.

터미널 텍스트 요약만 필요하면 이 스킬이 아니라 **`opm-usage-stats`** 스킬을 쓴다.

## 1. 데이터 조회

```bash
cd /Users/marcoyou/Projects/open-proxy-mcp && python3 scripts/usage_tracker.py --stats
```

매번 새로 조회한다(캐시 재사용 금지). 세션분할·KST 버킷·운영자 키 제외는 스크립트가 처리.

## 2. 값 도출

`--stats` 출력에서 뽑아 계산한다. **집계 규칙을 바꾸지 말 것**(수치 신뢰성).

**카드 4개 (규모+몰입 혼합):**

| 카드 | 출처 | 계산 |
|---|---|---|
| **외부 사용자 (명)** | `고유 사용자(외부)` | 그대로 |
| **누적 요청 (건)** | `총 요청(외부)` | 그대로 (`,` 천단위) |
| **재방문율 (%)** | `[요약]` 재방문 N / 전체 | `round(재방문/전체*100)` — 부제에 `(N/전체)` 병기 |
| **인당 체류 (시간)** | `[요약]` 평균 사용 분/인 | `분/60`, 소수1자리 |

**주 그래프 (콤보, 14일):** `[일별]` 표에서 날짜별 **단일사용자**(막대)와 **인당요청**(선, `요청/사용자`
컬럼 그대로)을 뽑는다. 막대=그 날 몇 명, 선=얼마나 깊게 썼나 → 규모+몰입을 한 그래프에.
**주말**(토·일)은 흐린 막대, **오늘(마지막·미완료일)**은 빗금 막대 + footer note "M/DD 진행 중"
(반일치를 완성치처럼 보이게 하지 말 것).

**푸터 보조 3개:** 누적 요청 · 집중도(`[집중도]` 상위 N% → `%`) · 평균 응답 ms(`[성능]`).

## 3. 슬라이드 생성 (생성 스크립트 사용)

SVG 콤보 차트는 좌표 계산이 있어 **손으로 고치지 말고 `gen_slide.py`(이 스킬 폴더)를 쓴다**:

1. `gen_slide.py`를 스크래치패드로 복사.
2. 상단 **`DAYS` 리스트**를 `[일별]` 최신값으로 교체 — `(날짜, 요일, 단일사용자, 인당요청, 주말여부,
   미완료여부)`. 마지막 날만 `is_partial=True`. `U_REF`(사용자축 max)·`R_REF`(인당요청축 max)는
   최댓값보다 살짝 큰 값으로 헤드룸 확보.
3. 카드 4개 값(`.card-value`/`.card-desc`)·기간(`.period`)·헤더 문구(`h1`, 캠페인 문구 원하면)·
   푸터 보조 3개(`.ctx`)를 HTML 본문에서 교체.
4. `python3 gen_slide.py <출력.html>` 실행 → `Artifact` 툴로 게시(`favicon:"📊"`, description에 기간).
   **같은 파일 경로로 재게시하면 URL 유지**(기존 슬라이드 갱신은 `url` 파라미터 또는 동일 경로).
5. 게시 후 사용자에게 **"슬라이드(1200×675)를 캡처해 업로드"** 안내(페이지 상단 힌트는 슬라이드
   밖이라 캡처에 안 잡힘).

`template.html`은 마지막 산출물 스냅샷(참고용) — 실제 갱신은 항상 `gen_slide.py`로.

## 4. 디자인 노트 (아이덴티티 — 리프레시 때 유지)

주제(DART 공시·거버넌스 데이터)에 맞춘 **"리서치 터미널"** 아이덴티티. 임의로 바꾸지 말 것:
- **라이트 테마 단일 커밋** — 흰 종이 바탕(`--paper #F6F7F9`) + 딥 네이비 잉크 텍스트(`--ink #16202E`)
  + 딥 앰버/골드 액센트(`--gold #AE7A1E`). LinkedIn 피드에서 깔끔·프로페셔널. 테마 토글 대응 안 함
  (캡처용 슬라이드라 의도된 단일룩). ※ 이전 다크안에서 사용자 요청으로 라이트로 전환(2026-07-12).
- **콤보 차트**: 막대=단일사용자(슬레이트블루 `--bar`), 선=인당요청(골드). 좌축=사용자, 우축=인당요청
  (이중축). faint 그리드 + 값 라벨. 주말 막대 흐림, 미완료일 빗금.
- **타이포**: 숫자는 모노스페이스(`--font-mono`)로 크게 = 데이터 리드아웃(터미널) 느낌, 한글은 시스템
  산세리프. 폰트 CDN 금지(CSP) — 시스템 스택만. `tabular-nums`.
- **질감**: 상단 골드 hairline 룰 + 카드 top 골드 라인 = 공시/원장(ledger) 뉘앙스.
- 사용자가 다른 강조를 원하면 카드/그래프 지표만 교체(성장=신규유입, 인게이지먼트=재방문·체류·집중도).

## 5. 원칙

- **개인정보**: 집계 수치만. `key_hash`·개별 사용자·쿼리 파라미터 노출 금지(운영자 키는 `--stats`가
  이미 제외). Top 사용자 표는 슬라이드에 넣지 않는다.
- **정직성**: 미완료 당일은 빗금+note로 표시. 런칭 코호트(6/29 증권사 리포트 유입) 등 급증 맥락이
  오해를 부를 수 있으면 부제/note로 한 줄 단서(원인 추정 대신 사실만).
- **Artifact 무결성**: 외부 리소스 금지(CSP) — CSS 인라인, 이미지 data URI. 가로 스크롤 금지
  (슬라이드는 `overflow-x:auto` 래퍼 안에). 차트는 `height` 고정(SVG가 세로로 늘어나 텍스트
  왜곡되는 것 방지).
