## 제안의 요점

정책·사실·권고·검토 상태를 분리합니다. LLM은 원문에서 후보 사실·정관 쟁점·소명·반증을 제안합니다. 계산과 규칙 적용은 고정된 엔진이 맡고 정성 판단은 검토자가 수용합니다. 반대 권고와 사람의 검토 필요를 동시에 보존합니다.

34개 규칙과 45개 지표·정보 정의를 포함합니다. 규칙은 모두 OPM 개편 제안이며 활성화하지 않았습니다. 기관별 정책은 비교 자료로만 포함했으며 완전한 기관별 실행팩이 아닙니다.

국민연금은 2026-07-02판 원문, 삼성은 공식 다운로드 문서 내부의 2025-02-27판을 확인했습니다. 미래에셋은 2026-01-30 개정 공지와 저장소 추출 데이터의 불일치를 확인했으며 첨부 본문 재확인이 필요합니다. 한국투자신탁운용은 현재 공개 페이지가 연결한 상세 DOC 원문을 확인했습니다. 파일명은 20240425이며 본문 시행일은 미표시입니다. CB/BW의 우선인수권 조건이 50%·20% 문턱에서 중복되는 문구는 공개 원문에도 있어 기관 해석 확인 전 해당 수치 규칙을 실행 보류해야 합니다.

## 형식 및 검증 범위

HTML 규칙·지표 목록은 policy.json에서 생성합니다. HTML 하단의 SHA-256은 JSON의 바이트 해시입니다. 규칙·지표 변경 시 생성기 → 검사기 → 문서 생성기를 순서대로 실행하여 동기화합니다.

```sh
python3 output/guideline-redesign-20260907/build_artifacts.py
uv run python output/guideline-redesign-20260907/validate_package.py
python3 output/guideline-redesign-20260907/render_documents.py
```

JSON Schema, ID·지표·출처 참조, 25개 가상 규칙 사례, 4개 산술 사례를 검사했습니다. 이 검사는 명세 일관성 확인입니다. 실제 기업 데이터 추출, 법적 적합성, 기관 투표 예측, 실제 MCP 통합 성능을 검증하지 않았습니다. 검증기의 사례는 선택한 규칙만 적용하는 교육용 예시이며 전체 카테고리 평가기가 아닙니다.

실제 운영에는 최신 기관별 조항 원문 검증, 법규·경과조치 감수, 안건 관계·후보 동일성·정정공시 계보, 검토자 권한 및 독립 평가가 추가로 필요합니다. 사용자 조회 결과는 OPM 서버에 기본 저장하지 않는 기존 원칙을 유지하며 감사 이력은 사용자 내보내기 또는 승인된 별도 저장소로 설계합니다.
