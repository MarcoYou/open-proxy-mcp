현재 코드의 동작 설명입니다. 예시는 가상이며, 이 화면에서 모델을 실행하거나 투표를 전송하지 않습니다.

세 주체가 주고받으며 판단합니다

위쪽 하네스가 진행을 통제하고, 가운데 MCP가 근거와 검증을, 아래 LLM이 독해와 판단을 맡습니다. 실선은 기본 진행, 점선은 추가 열람·보정 경로입니다.

차트는 좌우로 움직여 볼 수 있어요. 박스를 누르면 설명이 열립니다.

현재 4단계 실행기는 정관·이사 선출 구조 안건에 적용됩니다. 개별 이사 후보 평가는 별도 계약을 사용하며, 모든 종류의 안건이 같은 4단계를 거치는 것은 아닙니다.

사실을 먼저 고정하고, 판단을 쌓습니다

앞 단계의 결과를 바탕으로 다음 단계가 일합니다. 검증된 사실을 뒤 단계에서 마음대로 바꾸지 않도록 역할을 나눴습니다.

    각 화살표에서 코드 검증을 거칩니다. 검증된 결과를 고정해 다음 단계에 넘기고, 실패하면 해당 단계만 보정합니다.

    각 단계에 공통으로 들어가는 장치

    QA도 LLM의 평가입니다. 다른 모델이나 사람이 독립적으로 검토했다고 자동으로 간주하지 않으며, 결과에는 사람 미검토 표시가 유지됩니다.

    판단 성향과 처리 방법을 따로 설정합니다

    숫자가 높다고 언제나 반대하는 구조는 아닙니다. 각 값이 맡는 역할을 눌러서 확인해 보세요.

    stance·firmness는 판단에, automation은 최종 처리 분기에 반영↓
    전체 실행을 지원하는 별도 장치

    자동화는 권고안의 처리 준비 수준입니다. 실제 투표 전송은 지원하지 않으며, 오류·미평가·표 배분 같은 실행 조건을 완료로 둔갑시키지 않습니다.
