# screener 아침 디제스트 — 수주 / 임시주총

매일 아침, 시총 상위 200개 기업에서 어제 이후 새로 뜬 공시를 유형별로 훑어 폰으로 스캔하기 좋게
카드/표로 정리하는 루틴. `screener` tool 하나로 전체시장을 얕게 훑는다(개별 tool = 한 회사 깊게).

- **tool**: [screener](../../wiki/tools/screener.md)
- **공통 세팅**: `universe=top_mktcap:200`, `period=since_yesterday`, `details=true`
- **추천 스케줄**: 평일 아침(예: 08:00 KST). 주말은 신규가 거의 없어 스킵 가능.

> **왜 `since_yesterday`인가**: DART `list.json`은 접수"일자"만 주고 접수 "시각"이 없다. 그래서
> "지난 N시간" 같은 시간창은 데이터상 만들 수 없다. 공시 대부분이 전일 장 마감 후·밤사이 뜨므로
> `today`면 전날 저녁 물량을 통째로 놓친다. `since_yesterday`(=어제~오늘, 이틀치)가 이를 잡는다.
> 하루 1회 실행이면 "어제 이른 아침 것"이 살짝 겹치는 정도라 무해.
>
> **월요일 주의**: `since_yesterday`(일+월)면 금요일 저녁 물량을 놓친다. 필요하면 월요일 루틴만
> `period=last_7d`로 벌리거나 "지난 3영업일"로 지시.

## 레시피 1 — 수주 디제스트

시총 상위 200에서 새 단일판매·공급계약(수주)을 신규/정정으로 갈라 보여준다. ⭐ = 매출대비 임팩트.

```
매일 아침, 시총 상위 200개 기업에서 어제 이후 새로 뜬 단일판매·공급계약(수주)
공시를 훑어 디제스트로 정리해줘.

[조회]
- screener 툴, universe=top_mktcap:200, period=since_yesterday, details=true.
- 단일판매·공급계약(수주)만. 다른 유형은 무시.
- 단계 태깅을 보고 "신규 체결"과 "정정(기재/첨부정정)"을 반드시 구분해.

[출력 — 아래 형식을 매일 똑같이 지켜줘]
맨 위 제목: 🎌 오늘의 수주 — {날짜} (시총상위 200)

📣 헤드라인 3줄:
- 신규 체결과 매출대비 높은 건을 우선해서 오늘의 핵심을 폰으로 훑기 좋게.
- "최대어"를 언급하면 기준은 계약금액으로 통일.

🆕 신규 체결  (표, 시총 큰 순)
| 회사(시총) | 상대방 | 계약금액 | 매출대비 | 상태 | DART |
- 매출대비 10% 이상이면 회사명 앞에 ⭐.

🔧 정정  (표, 시총 큰 순)
| 회사(시총) | 상대방 | 금액(정정전→정정후) | 매출대비 | DART |
- 정정의 핵심은 바뀐 금액이야. 정정전→정정후 금액을 꼭 보여줘.
- diff를 못 구하면 현재 금액만 쓰고 "(정정전 금액 미상)"이라 솔직히 적고 원문 링크를 남겨.

📝 메모: 오늘 가장 주목할 1건만 한 줄로. (그 이상 늘리지 말 것)

맨 아래: 스캔 N건 → 수주 M건 (신규 X · 정정 Y).

[지켜야 할 것]
- 회사명 옆에 종목코드 같은 숫자 붙이지 마. 시총만.
- 진행상황·영어 상태로그("Screener succeeded…", "Sending…") 출력 금지. 결과만.
- "확인해 드릴 수 있습니다" 같은 대화체 금지 — 이건 답장 없는 알림이야.
- 값이 없으면 지어내지 말고 미상으로 두고 링크를 남겨.

신규·정정 둘 다 없으면 "오늘은 수주 없음"만. 스크리너 조회가 실패하면 실패했다고 솔직히.
```

## 레시피 2 — 임시주총 디제스트

시총 상위 200에서 새 임시주주총회 소집을 신규/정정으로 갈라 보여준다. ⭐ = 안건의 성격
(경영권·구조변경·주주제안) — 임시주총의 진짜 시그널.

```
매일 아침, 시총 상위 200개 기업에서 어제 이후 새로 뜬 임시주주총회 소집 공시를
훑어 디제스트로 정리해줘.

[조회]
- screener 툴, universe=top_mktcap:200, period=since_yesterday, details=true.
- 주주총회소집 공시 중 "임시주주총회"만. 정기주총(정기주주총회)은 제외.
- 단계 태깅을 보고 "신규 소집결의"와 "정정(기재/첨부정정)"을 반드시 구분해.

[출력 — 아래 형식을 매일 똑같이 지켜줘]
맨 위 제목: 🏛️ 오늘의 임시주총 소집 — {날짜} (시총상위 200)

📣 헤드라인 3줄:
- 경영권·지배구조가 걸린 안건과 주주제안 임시주총을 우선해서, 오늘의 핵심을
  폰으로 훑기 좋게.

🆕 신규 소집  (표, 시총 큰 순)
| 회사(시총) | 주총일 | 핵심 안건 | 소집주체 | 상태 | DART |
- 다음 중 하나라도 걸리면 회사명 앞에 ⭐:
  이사·감사 선임/해임, 정관변경, 합병·분할·영업양수도, 감자·자본감소,
  최대주주/지배구조 관련, 또는 주주제안·소수주주 소집청구 건.
- 소집주체는 회사(이사회) / 주주제안 중 어느 쪽인지 표시.

🔧 정정  (표, 시총 큰 순)
| 회사(시총) | 주총일 | 바뀐 내용(정정전→정정후) | DART |
- 임시주총 정정의 핵심은 "무엇이 바뀌었나" — 주총일 변경인지, 안건 추가·삭제인지.
- 정정전→정정후를 꼭 보여줘. 못 구하면 "(정정전 미상)"이라 솔직히 적고 원문 링크.

📝 메모: 오늘 가장 주목할 임시주총 1건만 한 줄로. (그 이상 늘리지 말 것)

맨 아래: 스캔 N건 → 임시주총 M건 (신규 X · 정정 Y).

[지켜야 할 것]
- 회사명 옆에 종목코드 같은 숫자 붙이지 마. 시총만.
- 진행상황·영어 상태로그("Screener succeeded…", "Sending…") 출력 금지. 결과만.
- "확인해 드릴 수 있습니다" 같은 대화체 금지 — 이건 답장 없는 알림이야.
- 안건·날짜가 불명확하면 지어내지 말고 미상으로 두고 원문 링크를 남겨.

신규·정정 둘 다 없으면 "오늘은 임시주총 없음"만. 스크리너 조회가 실패하면 실패했다고 솔직히.
```

## 설계 노트 (왜 이렇게 짰나)

- **신규 vs 정정 분리**: 신규 체결·소집결의가 진짜 뉴스다. 초기 실측에서 하루 수주 3건이 전부
  [기재정정]인 날도 있었는데(2026-07-15), 그럴 땐 정정 diff가 핵심이지 현재값이 아니다. 두 섹션으로
  갈라 신규를 위로 올린다.
- **정정 diff (정정전→정정후)**: 정정의 뉴스는 "바뀐 값". `details=true`로 문서를 열어 diff를 뽑되,
  파서가 이전값을 못 주면 "미상 + 링크"로 정직하게 degrade(조작값 금지).
- **⭐ 임팩트 플래그**: 시총순 정렬은 큰 회사를 위로 올리지만, **작은 회사의 매출대비 큰 계약**(또는
  경영권이 걸린 임시주총)이 진짜 사건일 때가 많다. 시총 정렬에 파묻히지 않게 ⭐로 끌어올린다.
- **형식 고정 + 나레이션 제거**: 루틴은 LLM이 매번 렌더링하므로 형식을 못박지 않으면 날마다 모양이
  흔들린다. 종목코드 누출·영어 상태로그·대화체를 명시적으로 금지.

## 알려진 한계 · 튜닝 포인트

- **정정 diff는 파서 의존**: `order_contracts`/`shareholder_meeting_notice` 파서가 정정전 값을
  실제로 노출하는지는 실행별로 다를 수 있다. 첫 실행 결과로 diff가 실제로 나오는지 확인 후, 안 나오면
  "미상" degrade가 잘 도는지 점검.
- **⭐ 기준은 임의값**: 수주 매출대비 10%, 임시주총 "경영권·구조변경·주주제안"은 시작값. 임시주총은
  ⭐가 너무 흔하면 "합병·분할·최대주주 변경" 같은 초대형 이벤트로만 좁힌다.
- **임시/정기 필터는 프롬프트 레벨**: screener `agm_notice`는 정기·임시를 다 긁는다. "임시만"은
  `report_nm`의 "임시주주총회" 키워드로 LLM이 거른다(툴 파라미터 아님).
- **cursor 미사용**: 하루 1회 실행 기준이라 커서 idempotency는 생략. N시간 반복으로 바꾸면 겹침이
  누적되므로, 그땐 `next_cursor`(반개구간) 또는 rcept_no high-water-mark가 필요.
