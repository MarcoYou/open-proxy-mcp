# valuation — 이런 질문에 답합니다

상대가치 배수 — PER·PBR·배당수익률(통화환산·스케일가드).

## 예시 질문
- "PER PBR 지금 얼마야?"
- "배당수익률 얼마?"
- "섹터 평균 대비 싸? 비싸?"

## 무엇이 돌아오나
종목 PER/PBR/배당수익률 + 섹터·시장 비교 + 시계열.
