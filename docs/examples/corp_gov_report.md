# corp_gov_report — 이런 질문에 답합니다

기업지배구조보고서 — 15개 핵심지표 준수 여부.

## 예시 질문
- "기업지배구조 핵심지표 몇 개나 준수해?"
- "집중투표·전자투표 도입했어?"
- "작년 대비 개선된 지표 있어?"

## 무엇이 돌아오나
15개 핵심지표 준수/미준수 + 연도별 변화.
