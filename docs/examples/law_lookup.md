# law_lookup — 이런 질문에 답합니다

정관↔법령 양방향 조회(회사·DART 무관).

## 예시 질문
- "집중투표 배제 조항 삭제하면 무슨 법 위반?"
- "상법 제542조의8 전문 보여줘"
- "감사위원 분리선출 근거 조문 뭐야?"

## 무엇이 돌아오나
정관/키워드 → 법령 조문(전문), 또는 법조문 → 정관 변경유형·우회·안건 신호.
