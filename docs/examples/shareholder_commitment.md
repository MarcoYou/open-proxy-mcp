# shareholder_commitment — 이런 질문에 답합니다

밸류업·배당·소각 **약속 vs 실제 이행** 추적(연중 스튜어드십).

## 예시 질문
- "작년에 발표한 배당·소각 약속 실제로 지켰어?"
- "자사주 소각으로 장부가 손익 얼마 났어?"
- "다년 주주환원율 어떻게 돼?"

## 무엇이 돌아오나
약속 대비 이행 + 자사주소각 장부가손익 + 주주환원율.
