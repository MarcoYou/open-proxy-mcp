# proxy_advise_before_meeting — 이런 질문에 답합니다

**의결권 보조**(핵심 도구) — 여러 data tool을 묶어 안건별 판단·근거를 낸다.

## 예시 질문
- "이번 주총 안건별로 찬성/반대 어떻게 봐야 해?"
- "이 이사 재선임 반대할 근거 있어?"
- "이 보수한도 인상 안건 어떻게 판단해?"

## 무엇이 돌아오나
안건별 찬성/반대/검토 + 근거(Open Proxy Guideline 기준).
