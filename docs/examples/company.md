# company — 이런 질문에 답합니다

회사를 식별하고 최근 공시 목록을 준다 — 모든 분석의 출발점.

## 예시 질문
- "삼성전자 정확한 corp_code랑 종목코드 뭐야?"
- "'카카오'라는 이름으로 상장사 여러 개면 뭐뭐 있어?"
- "이 회사 최근에 무슨 공시 냈어?"

## 무엇이 돌아오나
corp_code·종목코드·상장여부·동명 후보 + 최근 공시 인덱스.
