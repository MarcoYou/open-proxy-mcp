# 주총 의결권 보조

주주총회 **전에** 각 안건을 어떻게 의결할지 판단을 돕습니다.
소집공고의 안건을 구조화하고, 안건별로 **찬성(FOR) / 반대(AGAINST) / 검토(REVIEW)** 권고와 근거를 함께 제시합니다.
판단의 기준은 OPM 자체 **Open Proxy Guideline** (소수주주 보호·거버넌스 투명성·장기 가치·추적 가능성)입니다.

## 먼저 — 설계 원칙 3가지

1. **DART 공시 안의 정보만 판단합니다.** 외부 뉴스·평판·시장 루머는 보지 않습니다 — 그 영역은 사용자가 직접 확인합니다.
2. **반대(AGAINST)는 명백한 hard trigger에서만.** 애매한 우려는 자동 반대하지 않고 **검토(REVIEW)**로 애널리스트에게 넘깁니다.
3. **데이터가 없으면 자동 찬성하지 않습니다.** 근거 공시를 못 찾으면 `NO_DATA`로 본문 검토를 유도합니다 (잘못된 자동 FOR 방지).

## 반대(AGAINST)가 나오는 경우 — 이 4가지가 전부

| 안건 | AGAINST 조건 |
|---|---|
| 재무제표 승인 | **완전 자본잠식** (상장폐지 사유) |
| 재무제표 승인 | **감사의견 한정·부적정** (적정 아님) |
| 이사 선임 | **결격사유** (법적 자격 미달·미성년) |
| 감사위원 선임 | **장기연임** (5년 룰 위반 — 독립성 훼손) |

→ 그 외 모든 안건은 **FOR 또는 REVIEW**만 나옵니다. 보수 대폭 인상도, 집중투표 배제도 AGAINST가 아니라 **REVIEW**입니다 (OPM이 단정하지 않고 사용자가 판단).

## 안건 유형별 판단 매트릭스

| 안건 유형 | 찬성 (FOR) | 검토 (REVIEW) | 반대 (AGAINST) |
|---|---|---|---|
| **재무제표 승인** | 감사의견 적정 + 자본잠식 없음 | 데이터 미확인(NO_DATA) | 완전 자본잠식 / 한정·부적정 의견 |
| **사외이사 선임** | 독립성·결격 모두 clean | 독립성 우려(최대주주 관계·회사와 거래·이전 직원) / 장기연임 / 과거 회계 risk 이력 | 결격사유 / (감사위원) 장기연임 |
| **사내이사 재선임** | 결격 없음 + 재임성과 good·moderate | 재임성과 weak·bad (법정 결격 아니므로 검토) | 결격사유 |
| **사내이사 신규** | 결격사유 없음 (재임이력 없어 성과 N/A) | — | 결격사유 |
| **이사·감사 보수한도** | 소진율 적정 / 감액 / 소폭 변경 | 소진율 낮은데 인상 / 50%+ 대폭 인상 / 순익 둔화+인상 / 자본잠식 | (없음) |
| **퇴직금** | 형식적 변경(퇴직연금 도입 등) | 황금낙하산 키워드 / 규정 신설 / 2배+ 인상 | (없음) |
| **정관변경** | 형식적·오기정정 / 소수주주 보호 명문화 / 이사 충실의무 | 집중투표 배제 / 초다수결의 / 이사회 정원 축소 / 수권주식 증가 / 신주발행 조항 | (없음) |
| **자기주식** | 소각 (주주환원) | 처분 (우호 지분 형성 가능성) | (없음) |
| **배당** | 흑자 + 자본 양호 / 리츠 의무배당 | 적자 / 자본잠식 / 배당성향 200% 초과 | (없음) |

## 사내이사 재선임 — 재임성과 2×3 매트릭스

회사가 추천한 사내이사를 "결격만 없으면 찬성"으로 처리하면 **현상유지 편향**이 생깁니다.
OPM은 각 사내이사의 **재임기간 경영성과**를 6칸으로 점수화해 권고에 반영합니다.

| 지표 | 평균 (avg) | 추세 (trend) |
|---|---|---|
| **ROE** | 평균 점수 | 추세 점수 |
| **부채비율** | 평균 점수 | 재임기간 누적변화 점수 |
| **CSR** (배당+소각 / 순이익) | 평균 점수 | 추세 점수 |

각 칸: **good +2 / moderate +1 / weak 0 / bad -1** → 총점으로 등급 산출:

| 총점 | 등급 | 권고 |
|---|---|---|
| +7 이상 | good | 찬성 (FOR) |
| +3 이상 +6 이하 | moderate | 찬성 (FOR) |
| 0 이상 +2 이하 | weak | 검토 (REVIEW) |
| 0 미만 | bad | 검토 (REVIEW) |

> 성과가 bad여도 **자동 반대가 아니라 REVIEW**입니다 — 법정 결격사유가 아니므로 최종 판단은 사용자 몫입니다.

**특수 규칙**: 완전 자본잠식 → ROE·레버리지 평균 자동 bad / 손실+환원활동 → CSR weak / 손실+환원 없음 → CSR moderate(보수적 경영).

> 검증: KOSPI 100 + KOSDAQ 50 (n=128) — 분류 커버리지 100%, 분포 good 29.7% / moderate 45.3% / weak 18.0% / bad 7.0%.
