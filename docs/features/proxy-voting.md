# 주총 분석과 의결권 행사 권고

**정기·임시주주총회 전에 안건과 근거를 검토하고 의결권 판단을 돕습니다.** 소집공고를 구조화하고 안건·후보별 권고, 사유, 정책 인용, 공시 원문 발췌를 함께 제공합니다.

## 판정 읽는 법

| 판정 | 의미 | 다음 확인 |
|---|---|---|
| FOR · 찬성 | 엔진이 평가한 근거에서 찬성 판단 | 사유와 원문 확인. 회사·후보 전반에 대한 보증은 아닙니다. |
| AGAINST · 반대 | 결격, 강행규정 위반, 완전 자본잠식, 감사의견 한정·부적정·의견거절 등 명확한 사유 확인 | 인용된 사유와 해당 주총에 적용되는 조건 확인 |
| REVIEW · 검토 필요 | 우려·조건·경합 또는 추가 판단이 필요한 사항 | 사유와 근거를 검토해 판단. 기권 지시가 아닙니다. |
| NO_VOTE · 표결 없음 | 철회·보고사항 등 표결 대상이 아닌 안건 | 안건 기록에 남기되 찬반 권고로 해석하지 않습니다. |
| NO_DATA · 자료 부족 | 판정에 필요한 정보를 확보하거나 구조화하지 못함 | 첨부 원문을 읽고 필요하면 발췌를 넓혀 확인. 자료 부재는 자동 찬성이 아닙니다. |

위 영문 값은 구조화된 판정 값이며 기본 보고서는 한글 표기를 사용합니다. 영어 설명이 필요하면 연결한 AI에 판정·유의사항·인용을 유지해 설명하도록 요청할 수 있습니다.

## 정책과 근거

판단 기준은 OPM의 **Open Proxy Guideline**(소수주주 보호·거버넌스 투명성·장기 가치·추적 가능성)입니다. **정책 문서의 반대 기준과 엔진의 자동 AGAINST 조건은 다릅니다.** 장기연임·성과 저조 등은 별도 명확한 반대 사유가 없으면 대체로 REVIEW입니다. 5년 재임 경보만으로 자동 반대하지 않습니다. 이사회 출석률은 정책 기준에 있지만 현재 판정 트리거에는 미반영입니다.

권고에 인용된 정책 절을 요청하거나 `proxy_guideline(section="2.4")`로 확인하세요. 정책과 엔진의 대응표는 `proxy_guideline(section="0-A")`에 있습니다. [정책 원문](../../open_proxy_mcp/data/guideline/open-proxy-guideline.md) · [기술 상세](../../wiki/tools/proxy_advise_before_meeting.md).

- 사내이사 성과 평가는 연임 후보의 등기이사 재직 기간에 한정합니다. 성과 저조만으로는 REVIEW입니다.
- 집중투표·선임 정원·경합 후보·조건부 안건·부모와 자식 안건의 관계를 함께 읽어야 합니다. 개별 후보 권고만 떼어 표를 배분하면 안 됩니다.
- 공시 참조와 원문 발췌를 제공합니다. 근거 위치가 불확실하다는 표시가 있으면 발췌가 해당 안건인지 확인하고, 잘린 발췌는 넓혀 읽으세요. 공시 링크가 있다고 해당 절까지 정확히 매칭됐다는 뜻은 아닙니다.
- 권고는 공시 근거를 사용합니다. 뉴스 확인은 별도 `director_news`로 할 수 있지만, 키워드 검색 결과 자체는 확인된 사실이나 찬반 판정이 아닙니다.

## 회차와 분석 기준일

기본 `meeting_type="auto"`는 정기·임시 중 회차를 선택합니다. `annual`·`extraordinary`로 종류를 한정할 수 있으며 `year`는 사업연도가 아닌 주총 연도입니다. 응답의 선택된 회차와 선택 근거를 확인하세요. 명시한 종류의 소집공고가 없으면 회차를 만들지 않고 `no_filing`과 확인 가능한 공고 참조를 제공합니다.

`as_of="YYYYMMDD"`는 정보 기준일입니다. 기본값은 회의일이 오늘 또는 과거면 회의일 전일, 미래면 한국시간 오늘입니다. 회의일을 읽지 못하면 오늘을 사용하고 과거 분석에 사후 자료가 섞일 수 있음을 알립니다. `include_after_meeting=True`면 기준일 이후 공시를 경고와 함께 포함하지만 해당 회차의 의결 결과는 권고에 사용하지 않습니다. 실제 결과는 [주총 안건·결과](meeting-agenda.md)로 별도 조회합니다.
