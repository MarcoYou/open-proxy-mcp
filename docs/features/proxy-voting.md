# 주총 의결권 보조

**주주총회 전에, 각 안건을 어떻게 의결할지 판단을 돕습니다.** 소집공고 안건을 정리하고 안건별로 **찬성(FOR)·반대(AGAINST)·검토(REVIEW)** 권고와 근거를 함께 보여줍니다. "○○ 주총 안건 의견 알려줘"처럼 자연어로 물으면 됩니다.

판단 기준은 OPM의 **Open Proxy Guideline**(소수주주 보호·거버넌스 투명성·장기가치·추적가능성)이며, 다음을 지킵니다.

## 무엇을 답하나

- **반대(AGAINST)는 명백한 4가지에서만** 나옵니다 — 완전 자본잠식(재무제표 승인) · 감사의견 한정·부적정 · 이사 결격사유 · 감사위원 5년 장기연임(독립성 훼손). 넷 다 법·상장규정에 근거가 있습니다.
- 그 외 우려(보수 대폭 인상, 집중투표 배제 등)는 **단정하지 않고 검토(REVIEW)로** 넘깁니다 — OPM이 정책 판단을 대신하지 않습니다.
- **근거 공시를 못 찾으면 자동 찬성하지 않고** 검토로 넘겨 본문 확인을 유도합니다(무근거 자동 FOR 방지).
- 회사가 추천한 사내이사도 **재임기간 경영성과(수익성·안정성·주주환원 방향)를 반영**해 판단합니다. 단 성과가 나빠도 법정 결격이 아니면 반대가 아니라 REVIEW입니다.
- **REVIEW에는 항상 사유가 붙습니다**(독립성 우려·장기연임·소진율 낮은데 인상 등). 각 권고의 근거 공시는 [출처 추적](../../wiki/tools/evidence.md)으로 원문까지 확인할 수 있습니다.
- **DART 공시 안의 정보만** 봅니다 — 뉴스·평판·시장 루머는 사용자가 직접 확인합니다.
