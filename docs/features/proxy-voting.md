
# 주총 분석과 의결권 행사 권고

**주주총회 하나를 이름으로 물으면, 안건마다 찬성·반대·검토 초안과 근거를 받습니다.** 공개 서버의 의결권 권고 도구 4개가 소집공고와 관련 공시를 읽고, 의결권 가이드라인으로 판단한 뒤, 서버가 모든 권고를 검사합니다. 초안은 사람이 검토하지 않았고, 실제 투표·위임·전자투표는 보내지 않습니다.

## 네 단계

| 도구 | 하는 일 |
|---|---|
| `proxy_advice_start` | 주총 하나를 엽니다. 소집공고로 안건을 표결 단위로 나누고(택일·조건부 안건 포함), 후보 사실·배당과 현금·보수·감사의견·법원 경과를 모읍니다 |
| `proxy_advice_read` | 서버가 다 정리하지 않은 세부(후보 경력, 정관 조문, 보수 표 등)를 공시 원문의 해당 절에서 읽습니다 |
| `proxy_advice_rules` | 안건마다 적용될 가이드라인 규칙만 돌려줍니다 |
| `proxy_advice_finish` | 권고를 규칙과 사용자 성향에 비춰 검사하고, 문제가 있으면 돌려보내며, 통과하면 보고서를 씁니다 |

연결한 AI가 이 순서를 서버 안내문에서 읽어 알아서 부릅니다. 한 주총에 보통 3~10분 걸립니다. 이 네 도구는 공개 서버에서만 쓸 수 있습니다(가이드라인과 검사는 비공개 서버에서 돕니다).

## 판정 읽는 법

| 판정 | 의미 | 다음 확인 |
|---|---|---|
| FOR · 찬성 | 가이드라인 규칙이 찬성을 허용하고, 막는 사실이 없음 | 근거 한 줄과 인용 규칙 확인. 회사·후보 전반에 대한 보증은 아닙니다. |
| AGAINST · 반대 | 결격, 강행규정 위반, 성과와 무관한 보수 급증 등 규칙상 반대 사유 확인 | 인용된 규칙과 근거 공시 확인 |
| REVIEW · 검토 | 사람이 판단해야 할 사항이 남음 | 보고서의 「무엇이 확인되면 바뀌는지」를 보고 판단. 기권 지시가 아닙니다. |

보고서 끝에는 사람이 직접 확인할 점(예: 가처분 결과에 따라 안건이 실제로 상정되는지)이 따로 정리됩니다.

## 판단 기준과 읽는 자료

- **판단 기준시각:** 이 시각 전에 공개된 공시만 씁니다. 말하지 않으면 주총 전날 17:00(한국시간)입니다.
- **읽는 자료:** 소집공고와 소집결의, 최신 사업보고서와 첨부 정관, 감사의견, 의결권 권유·의견표명서, 법원·가처분 공시.
- **가이드라인:** 안건 유형 10개(재무제표·배당·정관·이사·감사·보수·자기주식·합병·분할·자본·주주제안)별 규칙. 모든 권고는 허용된 규칙에 기대야 서버 검사를 통과합니다.
- **성향:** 주주 개입 성향(보수적·중립·적극적)과 판단 확정 성향(결론우선·균형·신중)을 고를 수 있습니다.
