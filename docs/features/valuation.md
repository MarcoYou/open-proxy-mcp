# 밸류에이션

DART 공시와 KRX 공식 시세를 묶어 **PER·PBR·배당수익률 같은 상대가치 배수**를 계산합니다.
DART에서 받은 재무를 그대로 쓰지 않고, 지배주주 귀속 기준으로 맞추고 원화가 아닌 기능통화는
한국은행(ECOS) 환율로 자동 환산해 정리합니다. 적자·자본잠식처럼 배수가 의미 없어지는 경우는
숫자를 억지로 내지 않고 **N/M(측정 불가)**으로 표시합니다.

## 5개 보기(scope)

| scope | 무엇을 보나 |
|---|---|
| **firm** (기본) | 특정 기업 심층 — PER(FY0·TTM) · PBR(MRQ) · 배당수익률, 실시간 시세 기준 |
| **market** | 시장 전체(KOSPI·KOSDAQ) 시총가중 PER/PBR + 주간 추이 |
| **sector** | 산업(KSIC)별 배수 표 + 기업 vs 소속 섹터 비교 + 섹터 시계열 |
| **firm_history** | 한 종목의 PER/PBR 시계열 — FY0·TTM·MRQ 세 기준(주간 곡선 + 월말 요약) |
| **explain** | "이 PER 어떻게 나온 거야?" — 계산 과정·기준·출처를 실제 값으로 풀어 설명 |

## 세 가지 이익·자본 기준 — FY0 / TTM / MRQ

같은 PER·PBR도 어느 시점 숫자를 쓰느냐에 따라 값이 달라집니다. 섞으면 조용히 틀어지므로 기준을
항상 명시합니다.

- **FY0**: 가장 최근 확정 사업연도(연간) 순이익 기준 PER.
- **TTM**: 최근 4분기 합산(Trailing Twelve Months) 지배주주 순이익 기준 PER — 분기 실적 변화를 반영.
- **MRQ**: 가장 최근 분기말(Most Recent Quarter) 지배주주 자본 기준 PBR.

시가총액 기반으로 계산하므로 액면분할·유상증자 같은 수정주가 조정과 무관하게 시계열이 일관됩니다.

## 무엇을 참고하고 무엇을 연산하나

| 참고 항목 | 연산 지표 |
|---|---|
| 시가총액 ÷ 지배주주 순이익(FY0·TTM) | **PER** (주가수익비율) |
| 시가총액 ÷ 지배주주 자본(MRQ) | **PBR** (주가순자산비율) |
| 주당배당금 ÷ 주가 | **배당수익률** |
| 비KRW 기능통화 재무 × ECOS 환율 | **원화 환산 배수** (예: USD 기능통화사) |
| 적자·자본잠식·비정상 스케일 감지 | **N/M 게이팅 + 스케일가드** |

> 한국 기준 — 순이익·자본은 지배주주 귀속, 재무제표는 연결 우선. 시세·시총은 KRX 공식 데이터.

## 어떻게 쓰나

> "두산밥캣 PBR 얼마야?"

USD 기능통화 재무를 한국은행 환율로 자동 환산해 PBR을 계산하고, 어느 기준(FY0/TTM/MRQ)인지와
환산 내역을 함께 보여줍니다. `scope="explain"`으로 물으면 그 수치가 나온 계산 과정을 풀어줍니다.
