# 밸류에이션

**DART 공시와 KRX 공식 시세를 묶어 PER·PBR·배당수익률 같은 상대가치 배수를 계산합니다.** 전부 확정·실적(trailing) 기준이며, 애널리스트 추정 같은 **포워드(forward) 수치는 내지 않습니다.**

## 무엇을 답하나

- **PER·PBR·배당수익률**(현재 주가 기준)을 냅니다. 같은 PER도 어느 시점 숫자냐에 따라 달라지므로 **FY0(최근 확정 연간) · TTM(최근 4분기) · MRQ(최근 분기말)** 중 어느 기준인지 항상 표시합니다. 예: `PER 12.3x (TTM, 지배주주) · PBR 1.1x (MRQ)`.
- 순이익·자본은 **지배주주 귀속**, 재무는 **연결 우선**. 원화가 아닌 기능통화(예: USD) 회사는 **한국은행(ECOS) 환율로 자동 환산**합니다(두산밥캣 등).
- **적자·자본잠식처럼 배수가 의미 없어지면 숫자를 억지로 내지 않고 N/M(측정 불가)으로** 표시합니다.
- 한 기업 심층뿐 아니라 **시장 전체·산업(섹터) 비교, 종목 히스토리**, 그리고 "이 PER 어떻게 나온 거야?"라는 **계산 근거 풀이**도 답합니다.
- 출처: DART 재무·유통주식수·배당 + KRX 시세 + ECOS 환율. 상세 → [valuation](../../wiki/tools/valuation.md).
