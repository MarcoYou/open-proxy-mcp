# 지분·지배구조 맵

회사의 소유 구조(누가 얼마를 보유하고 누구와 엮여 있는지)를 공시 항목으로 구성합니다.

## 무엇을 참고하고 무엇을 연산하나

| 참고 공시 항목 | 무엇을 연산·판단 |
|---|---|
| 사업보고서 **최대주주 및 그 특수관계인 현황**의 보유주식수·지분율 | 최대주주 본인 **단독 지분** + 본인+특수관계인 **합산 지분**을 구분 연산 (집계 기준이 달라 혼동 방지) |
| **주식총수현황**의 발행주식총수 + 위 명부 + 자기주식 | 발행총수를 **100%로 정합 분해** (최대주주+특관 / 자사주 / 기타 소액주주) |
| **대량보유상황보고서(5%)**의 보유자·지분율 | 외부 5% 이상 보유자 식별 (기관·외국인·행동주의 등). 최다 보고자를 "5% 실세"로 표시 |
| **임원·주요주주 특정증권등 소유상황보고서** | 임원·10% 주주 보유 현황 |
| 자기주식 보유량 | 의결권 없는 자사주 비중 (표 대결 영향) |
| 보고자 이름 vs 최대주주 명부(registry_overlap) | 각 주체가 대주주 본인 계열인지 외부인지 표시 |

핵심은 **지배력의 실제 크기**입니다 — 최대주주가 안정적으로 지배하는지, 외부 세력과 표가 팽팽한지를 가늠합니다. 명부상 지분(본인+특관)과 5% 대량보유 보고(보고자 합산)는 **집계 기준이 달라 단순 합산하지 않으며**, 100% 분해는 명부 기준으로만 합니다.

## 5개 보기(scope)

| scope | 무엇을 보나 |
|---|---|
| **summary** | 지분 구조 종합 — 명부 단독/특관 구분, 발행총수 **100% 구성**(최대주주+특관/자사주/기타), 5% 실세 |
| **major_holders** | 최대주주 + 특수관계인 명부 (본인·친인척·계열사) |
| **blocks** | 5% 대량보유 — 최신 + 과거 이력(history) |
| **control_map** | 지배 구조 관계도 |
| **changes** | 지분 변동 내역 — **최대주주변동신고서 + 5% 대량보유 변동 통합**(분쟁사는 5% 보고로 지분이 움직임) |

> 자사주(자기주식)는 별도 기능으로 분리되어 있습니다 (이 tool에서는 폐기).

## control_map — registry_overlap

지배 구조 관계도에서 각 주체가 **최대주주 명부에 있는지(registry_overlap)**를 표시합니다.

- `registry_overlap = true` — 신고자 이름이 사업보고서 최대주주 명부에 존재 (대주주 본인 계열로 추정)
- `registry_overlap = false` — 명부에 없음 (외부 세력 가능성)

> registry_overlap은 **같은 이름이 명부에 있는지**를 뜻하며, 현재 이해관계가 완전히 같다는 의미는 아닙니다 (동명이인·이해관계 변화 가능).

## 어떻게 쓰나

> "SK하이닉스 지분 구조랑 최대주주 알려줘"

최대주주-특수관계인-5%가 정리된 지분 표로 나옵니다.
