# 지분·지배구조 맵

**누가 회사를 얼마나 쥐고 있는지** — 최대주주·특수관계인, 5% 이상 대량보유자, 자기주식까지 한 장으로 정리합니다. 핵심은 **지배력의 실제 크기**입니다: 최대주주가 안정적으로 지배하는지, 외부 세력과 표가 팽팽한지.

## 무엇을 답하나

- **최대주주 단독 지분**과 **본인+특수관계인 합산 지분**을 구분해 보여줍니다(집계 기준이 달라 섞으면 오해가 생김).
- 발행주식총수를 **100%로 분해**합니다 — 최대주주+특관 / 자기주식 / 나머지 소액주주(명부 기준).
- 외부 **5% 이상 보유자**(기관·외국인·행동주의 등)를 따로 식별합니다. 단, 명부 지분과 5% 보고는 집계 기준이 달라 단순 합산하지 않습니다.
- 지분 **변동**(최대주주 변경 + 5% 보고)을 시점순으로 추적합니다 — 분쟁·행동주의가 먼저 드러나는 곳입니다.
- 각 주체가 **대주주 본인편인지 외부인지**는 최대주주 명부에 같은 이름이 있는지로 표시합니다(동명이인·이해관계 변화 가능).
- 출처: DART 사업보고서 최대주주 현황·주식총수·5% 대량보유 보고. 상세 → [ownership_structure](../../wiki/tools/ownership_structure.md).
