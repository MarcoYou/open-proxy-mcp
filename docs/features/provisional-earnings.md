# 잠정실적 속보

**분기 실적이 확정되기 전, 회사가 먼저 내는 "영업(잠정)실적" 공시를 표로 정리합니다.** 매출·영업이익·순이익과 전년동기 대비 증감률을 공시 원문 표 그대로 — 어닝 시즌 속보 체크에 씁니다.

## 무엇을 답하나

- **잠정 매출·영업이익·순이익**과 **전년동기 대비 증감률(YoY)** — 공시의 원문 표를 그대로 보여주고, 핵심 수치는 구조화해 요약합니다.
- **연결/별도 기준**과 단위를 함께 표시합니다.
- 재무 숫자가 아닌 잠정공시도 흡수합니다 — 자동차 회사의 판매대수, 식품사의 지역별 매출처럼 서식이 달라도 원문 표로 반환합니다.
- 기간을 넓히면 최근 몇 분기의 잠정실적 공시를 시간순으로 모아 줍니다.
- [전체시장 공시 디제스트](../../wiki/tools/screener.md)에서도 잠정실적 카드가 떠서, 아침 루틴에서 "오늘 잠정실적 낸 회사"를 한 번에 볼 수 있습니다.
- 출처: DART 수시공시(영업·잠정실적, 공정공시). 상세 → [provisional_earnings](../../wiki/tools/provisional_earnings.md).
