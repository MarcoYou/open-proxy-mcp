# 밸류에이션

**DART 공시와 KRX 공식 시세를 묶어 PER·PBR·배당수익률 같은 상대가치 배수를 계산합니다.** PER·PBR 배수는 확정·실적(trailing) 기준입니다. 시장·산업 표에는 애널리스트 추정으로 집계한 **선행 PER·PBR** 을 옆에 함께 싣고, 배당수익률은 확정(사업연도 DPS)과 선행(추정 DPS) 두 벌로 냅니다. 종목 하나의 포워드 실적·배수(내년 PER 등)는 `forward_estimates_data`가 맡습니다.

## 무엇을 답하나

- **PER·PBR·배당수익률**(현재 주가 기준)을 냅니다. 같은 PER도 어느 시점 숫자냐에 따라 달라지므로 **FY0(최근 확정 연간) · TTM(최근 4분기) · MRQ(최근 분기말)** 중 어느 기준인지 항상 표시합니다. 예: `PER 12.3x (TTM, 지배주주) · PBR 1.1x (MRQ)`.
- 순이익·자본은 **지배주주 귀속**, 재무는 **연결 우선**. 원화가 아닌 기능통화(예: USD) 회사는 **한국은행(ECOS) 환율로 자동 환산**합니다(두산밥캣 등).
- **적자·자본잠식처럼 배수가 의미 없어지면 숫자를 억지로 내지 않고 N/M(측정 불가)으로** 표시합니다.
- 한 기업 심층뿐 아니라 **시장 전체·산업(섹터) 비교, 종목 히스토리**, 그리고 "이 PER 어떻게 나온 거야?"라는 **계산 근거 풀이**도 답합니다.
- **시장·업종 선행 PER·PBR**: 코스피·코스닥과 WICS 대분류·중분류(하위업종 28)마다 추정 기반 선행 배수를 트레일링 옆에 둡니다. 트레일링과 같은 방식(적자 추정도 더함)으로 합산하고, 추정이 있는 종목 수를 괄호로 함께 적습니다.
- 출처: DART 재무·유통주식수·배당 + KRX 시세 + ECOS 환율. 상세 → [price_multiple_data](../../wiki/tools/price_multiple_data.md).
