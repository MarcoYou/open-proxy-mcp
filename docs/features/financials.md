# 재무지표

**재무제표를 불러와 ROE(자기자본이익률) 같은 핵심 지표 수십 개를 자동 계산합니다.** DART 숫자를 그대로 보여주는 데 그치지 않고, 수익성·안정성·현금흐름을 한눈에 볼 수 있는 비율로 가공합니다.

## 무엇을 답하나

- **수익성**(ROE·ROA·영업이익률), **안정성**(부채비율·자본잠식 여부), **현금흐름**(잉여현금흐름·현금전환주기), 그리고 **감사의견 추이**까지 봅니다.
- 순이익은 **지배주주 귀속**, 재무제표는 **연결 우선**으로 맞춥니다 — 소수주주 섞인 값으로 계산해 지주사·자회사가 많은 한국 시장에서 틀어지지 않게.
- 분기를 물으면 **어느 기준 숫자인지(당기 3개월 / 누적 / TTM)를 결과에 항상 표시**합니다 — 섞으면 비율이 조용히 틀어지기 때문입니다. 회전일수·현금전환주기는 단일 분기를 연율화할 때 생기는 왜곡을 피하려 TTM(최근 4분기) 기준으로 냅니다.
- 심화로 ROE 듀퐁 분해, 장부이익-현금흐름 괴리도 제공합니다.
- 출처: DART 재무제표(재무상태표·손익·현금흐름)·감사보고서 endpoint. 상세 → [financial_metrics](../../wiki/tools/financial_metrics.md).
