# 재무지표

회사의 재무제표를 불러와 **ROE(자기자본이익률) 같은 핵심 지표 수십 개를 자동으로 계산**해줍니다.
DART에서 받은 숫자를 그대로 보여주는 데 그치지 않고, 수익성·안정성·현금흐름을 한눈에 볼 수 있는 비율로 가공해서 정리합니다.

## 6개 보기(scope)

| scope | 무엇을 보나 |
|---|---|
| **summary** | 핵심 지표 요약 (당기 + 전기) |
| **yearly** | 연도별 지표 (다년도) |
| **quarterly** | 분기별 지표 (4Q × 다년, standalone 3개월 기준 + QoQ·YoY 기본 동봉, 마진은 %p. Q4는 연간−3분기 누적 차분) |
| **yoy** | 전년 대비 (Year-over-Year) |
| **qoq** | 전분기 대비 (Quarter-over-Quarter, 양쪽 모두 standalone 기준) |
| **audit_opinion** | 감사인·감사의견 추이 |

## 분기 조회 시 기준 — 당기 / 누적 / TTM

DART는 보고서마다 항목별 기간 의미가 다릅니다. **손익**은 당기 3개월(누적은 별도), **현금흐름**은 누적, **재무상태**는 잔액입니다. 이를 섞으면 비율이 조용히 틀어지므로(예: 영업현금흐름÷영업이익이 6개월÷3개월), 분기·반기 보고서를 조회하면 다음을 자동 처리합니다.

- **손익 두 기준**: 누적(연초~보고시점, YTD)을 기본으로 하고, 반기·3분기는 **당기 분기(standalone, 3개월)**를 직전 보고서와 차분해 별도로 함께 제공합니다.
- **회전일수(DSO·DIO·현금전환주기)는 TTM(최근 4분기) 기준**: 한 분기 실적을 1년으로 늘려 쓰면 호황·급변기에 값이 왜곡(매출채권이 늘어도 회수일수가 줄어드는 식)되므로, 최근 4분기 매출을 분모로 써서 연간치와 직접 비교할 수 있게 합니다.
- **ROE·ROA는 연환산하지 않고** 해당 기간값으로 두되, "분기 기준"임을 함께 표시합니다.
- 어느 기준인지(`당기/누적/TTM`)는 결과에 **항상 명시**됩니다.

연도를 지정하지 않으면 분기 보기는 가장 최근 분기(이미 공시된)를, 연간 성격의 보기(summary·yearly)는 직전 사업연도를 봅니다.

## 무엇을 참고하고 무엇을 연산하나

사업보고서 재무제표(재무상태표·손익계산서·현금흐름표)의 계정 항목으로 다음을 연산합니다.

| 참고 항목 | 연산 지표 |
|---|---|
| 당기순이익(지배주주) ÷ 자기자본 | **ROE** (자기자본이익률) |
| 당기순이익 ÷ 총자산 | **ROA** (총자산이익률) |
| 영업이익 ÷ 매출 | **영업이익률** |
| 부채 ÷ 자기자본 | **부채비율** |
| 자기자본 vs 자본금 | **자본잠식 여부** (부분/완전) |
| 감사보고서의 감사의견 | **적정/한정 추이** |

**심화 지표**: ROE 듀퐁 3단 분해(마진·자산회전율·레버리지), 잉여현금흐름(FCF), 현금전환주기(CCC), 장부이익-현금흐름 괴리.

> 한국 기준 — 순이익은 지배주주 귀속, 재무제표는 연결 우선.

## 어떻게 쓰나

> "포스코홀딩스 최근 3년 ROE랑 부채비율 어떻게 변했어?"
