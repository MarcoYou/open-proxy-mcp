# 재무지표

DART 재무 endpoint를 통합해 **핵심 재무 지표**를 한 번에 산출합니다.
한국 표준(연결, 지배주주 귀속) 기준이며, 단순 수치뿐 아니라 분해·파생 지표까지 자동 계산합니다.

## 6개 보기(scope)

| scope | 무엇을 보나 |
|---|---|
| **summary** | 핵심 지표 요약 (당기 + 전기) |
| **yearly** | 연도별 지표 (다년도) |
| **quarterly** | 분기별 지표 (4Q × 다년) |
| **yoy** | 전년 대비 (Year-over-Year) |
| **qoq** | 전분기 대비 (Quarter-over-Quarter) |
| **audit_opinion** | 감사인·감사의견 추이 |

## 자동 산출 지표

DART가 주는 raw 계정값뿐 아니라, 분석에 바로 쓰는 파생 지표를 직접 계산합니다.

- **수익성 / 안정성 / 성장성** — ROE·ROA·영업이익률·부채비율 등
- **듀퐁 3단 분해** — ROE = 순이익률 × 자산회전율 × 재무레버리지
- **현금흐름** — FCF(잉여현금흐름), NWC(순운전자본)
- **운전자본 회전** — CCC(현금전환주기, Cash Conversion Cycle)
- **회계 품질** — accruals_gap(이익과 현금흐름의 괴리), 감사의견 추이
- **자본 상태** — 자본잠식 여부(partial/full) — 의결권 판단의 hard trigger와 연결

> 한국 표준: 순이익은 **지배주주 귀속** 기준, 재무제표는 **연결(CFS)** 우선.

## 어떻게 쓰나

> "포스코홀딩스 최근 3년 재무지표랑 ROE 듀퐁 분해 보여줘"

수익성·안정성·현금흐름 지표가 시점별로 정리되어 나옵니다.
