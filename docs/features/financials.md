# 재무지표

회사의 재무제표를 불러와 **ROE(자기자본이익률) 같은 핵심 지표 수십 개를 자동으로 계산**해줍니다.
DART에서 받은 숫자를 그대로 보여주는 데 그치지 않고, 수익성·안정성·현금흐름을 한눈에 볼 수 있는 비율로 가공해서 정리합니다.

## 6개 보기(scope)

| scope | 무엇을 보나 |
|---|---|
| **summary** | 핵심 지표 요약 (당기 + 전기) |
| **yearly** | 연도별 지표 (다년도) |
| **quarterly** | 분기별 지표 (4Q × 다년, standalone 3개월 기준 + QoQ·YoY 기본 동봉. Q4는 연간−3분기 누적 차분) |
| **yoy** | 전년 대비 (Year-over-Year) |
| **qoq** | 전분기 대비 (Quarter-over-Quarter, 양쪽 모두 standalone 기준) |
| **audit_opinion** | 감사인·감사의견 추이 |

## 무엇을 참고하고 무엇을 연산하나

사업보고서 재무제표(재무상태표·손익계산서·현금흐름표)의 계정 항목으로 다음을 연산합니다.

| 참고 항목 | 연산 지표 |
|---|---|
| 당기순이익(지배주주) ÷ 자기자본 | **ROE** (자기자본이익률) |
| 당기순이익 ÷ 총자산 | **ROA** (총자산이익률) |
| 영업이익 ÷ 매출 | **영업이익률** |
| 부채 ÷ 자기자본 | **부채비율** |
| 자기자본 vs 자본금 | **자본잠식 여부** (부분/완전) |
| 감사보고서의 감사의견 | **적정/한정 추이** |

**심화 지표**: ROE 듀퐁 3단 분해(마진·자산회전율·레버리지), 잉여현금흐름(FCF), 현금전환주기(CCC), 장부이익-현금흐름 괴리.

> 한국 기준 — 순이익은 지배주주 귀속, 재무제표는 연결 우선.

## 어떻게 쓰나

> "포스코홀딩스 최근 3년 ROE랑 부채비율 어떻게 변했어?"

수익성·안정성·현금흐름 지표가 시점별로 정리되어 나옵니다.
