# 경영권 분쟁 시그널

경영권 분쟁·행동주의(주주가 경영에 적극 개입하는 움직임)의 **신호**를 공시에서 모아 구성합니다.
OPM은 "분쟁이다/아니다"를 단정하지 않고 신호를 구조적으로 나열하며, 최종 판단은 애널리스트가 합니다.

## 무엇을 참고하고 무엇을 연산하나

| 참고 공시 항목 | 무엇을 연산·판단 |
|---|---|
| **소송등의제기** 공시의 "사건의 명칭" | 정정 공시 제외 후 경영권/상거래/미상 분류 + 제기/판결 단계 구분 |
| **대량보유상황보고서(5%)**의 보유주식수·지분율 | 시계열로 지분 변동 추적, 직전 대비 ±5%p 이상 급변(매집/exit) 감지 |
| 대량보유보고서의 **보유목적** 항목 | 단순투자 → 경영참여 목적 전환 판단 |
| **의결권대리행사권유참고서류 / 공개매수신고서** 존재 | 위임장 대결·공개매수 시도 여부 |
| 보고자 이름 vs **사업보고서 최대주주 명부** | 지분 매집 주체를 대주주 본인 / 외부 세력으로 구분 |
| **주주총회 결과**(찬반율·부결 안건) | 주총 후 분쟁 강도(안정/주의/분쟁 가능) 등급 연산 |

## 6개 보기(scope)

| scope | 무엇을 보나 |
|---|---|
| **summary** | 분쟁 신호 종합 (아래 항목 한눈에) |
| **fight** | 위임장 권유·공개매수 등 직접 대결 공시 |
| **litigation** | 소송 — 분류·중복제거 + 본문 사건명 파싱 |
| **signals** | 5% 대량보유 동학 + 목적 전환 |
| **timeline** | 분쟁 관련 공시 시점순 |
| **vote_math** | 주총 이후 표 계산 + 분쟁 강도 등급 |

## 소송 — 4단계 분류

소송 공시는 단순 나열하지 않고, 중복(정정 포함)을 제거한 뒤 성격·단계를 분류합니다.

- **성격(dispute_kind)**: 경영권(management) / 상거래(commercial) / 미상(unspecified)
  - 미상은 공시명 → 회사 단위 추정 → **본문 "사건의 명칭" 파싱** → LLM 위임 순으로 정밀화
- **단계(litigation_type)**: 제기(filed) / 판결(ruling) / 기타(other)

## 5% 대량보유 동학

대량보유보고서(5%) 시계열에서 **세력의 움직임**을 봅니다.

- **목적 전환** — 단순투자 → 경영참여로 보유목적이 바뀐 시점
- **지속 추가매입** — 보고 빈도·방향(증가/감소)
- **급변 강조** — 직전 대비 **±5%p 이상** 지분 변동 (매집/exit 양방향)
- **세력 구분** — 능동적 5% 신고를 `registry_overlap`(대주주 본인) vs 외부 세력으로 분리
  - registry_overlap = 신고자 이름이 사업보고서 최대주주 명부에 있는지로 판정

## 분쟁 강도 등급 (vote_math)

주총 **이후** 표 계산을 근거로 분쟁 강도를 3단계로 표시합니다.

| 등급 | 조건 |
|---|---|
| **contestable** | 부결 안건 발생 / 또는 주주측 세력 + (외부 5%+ 또는 고반대 안건) |
| **watch** | 소송 존재 / 외부 5%+ / 대주주측 5%+ / 고반대 안건 |
| **stable** | 위 신호 없음 |

> signal_level은 **주총 이후(vote_math) 전용**입니다 — 실제 표 대결 결과가 있어야 산출됩니다.

## 어떻게 쓰나

> "고려아연 경영권 분쟁 관련 신호 정리해줘"

소송·5% 동학·위임장·공개매수가 시점순으로 묶여 나옵니다.
