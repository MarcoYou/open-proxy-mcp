# 경영권 분쟁 시그널

**경영권 분쟁·행동주의(주주가 경영에 적극 개입하는 움직임)의 신호를 공시에서 모아 시점순으로 정리합니다.** OPM은 "분쟁이다/아니다"를 **단정하지 않고 신호만 나열하며, 최종 판단은 애널리스트의 몫**입니다.

## 무엇을 답하나

- **소송 · 5% 대량보유 동학 · 위임장 권유 · 공개매수**를 한데 묶어 시점순으로 보여줍니다.
- 5% 대량보유 보고에서 **보유목적이 단순투자 → 경영참여로 바뀐 시점**과, 직전 대비 지분이 크게 움직인(매집/이탈) 구간을 짚습니다.
- 지분을 움직인 주체가 **대주주 본인편인지 외부 세력인지** 구분합니다 — 신고자 이름이 사업보고서 최대주주 명부에 있는지로 판정하되, 같은 이름이라고 이해관계가 같다는 뜻은 아닙니다(동명이인 가능).
- 소송은 정정·중복을 제거하고 **경영권 / 상거래 / 미상**으로 성격을 나눠 정리합니다.
- 주총 결과가 있으면 **분쟁 강도(안정 / 주의 / 분쟁 가능)**를 표시합니다 — 이 등급은 실제 표 대결 결과가 있는 **주총 이후에만** 산출됩니다(사전에는 나오지 않습니다).
- 출처: DART 소송·대량보유·위임장·공개매수 공시. 상세 → [proxy_contest](../../wiki/tools/proxy_contest.md).
