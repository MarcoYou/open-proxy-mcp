# 주주환원

배당·자기주식·기업가치제고계획(밸류업)을 묶어 **주주환원 이행 여부**를 봅니다.
"약속(정책)"과 "실제 집행(사실)"을 함께 놓고 비교하는 것이 핵심입니다.

## 1. 배당 — 실지급 사실

**현금·현물배당결정** 공시와 사업보고서의 **배당에 관한 사항**에서 다음 항목을 참고·연산합니다 (미래 약속이 아닌 확정·실지급 사실).

- **주당배당금(DPS)·배당금총액** — 공시 항목을 그대로 참조
- **배당성향** — 배당금총액 ÷ 당기순이익으로 연산
- **시가배당률** — 주당배당금 ÷ 기준일 주가로 연산
- **배당 구분** — 배당결정 공시의 결산/중간/분기 구분 항목으로 지급 주기 식별
- **연도별 추이** — 사업보고서의 배당에 관한 사항(다년 컬럼)을 권위 출처로 증감·일관성 판단 (결정공시 합산 아님)
- **중간배당 진행분** — 최신 연도 결산이 미확정이면 분기·반기보고서 누적값으로 "N분기까지 확정"을 표시

조회 단위(scope): **summary**(요약) · **detail**(배당결정 공시 상세 — 기준일·지급일) · **history**(연도별 추이).

## 2. 자기주식 — 취득→처분→소각 사이클

자사주 **취득·처분·소각·신탁** 결정/결과 공시를 집계하고, **결정-결과를 사이클로 매칭**합니다.

- 취득한 자사주가 실제 **소각**으로 이어졌는지가 환원의 질을 가릅니다 (취득만 하고 소각 안 하면 환원 효과 약함)
- `for_cancelation` 플래그 — 취득목적에 "소각"이 명시된 경우 (별도 소각결정 없이도 소각 의도 포착)

| scope | 무엇을 보나 |
|---|---|
| **summary** | 자사주 이벤트 종합 |
| **annual** | 연도별 취득·처분·소각 집계 |

## 3. 밸류업 — 정책·미래 약속

기업가치제고계획(밸류업) 공시와 핵심 commitment 문장을 봅니다.

- 각 공시를 **future_plan(계획) / implementation_status(이행 현황) / implementation_result(결과) / meta_reference(메타)**로 분류
- **자사주 소각 이행과 교차참조** — 약속(밸류업) 대비 실제 집행(자사주 소각)을 연결

| scope | 무엇을 보나 |
|---|---|
| **summary** | 밸류업 공시 종합 |
| **plan** | 계획 본문 + plan title |
| **commitments** | 핵심 약속 문장 |
| **timeline** | 공시 시점순 추이 |

## 어떻게 쓰나

> "KT&G 배당이랑 자사주 소각 이력, 밸류업 계획 이행됐는지 봐줘"

정책(밸류업) → 약속 → 실제 집행(배당·자사주 소각)을 한 흐름으로 확인합니다. 이 3개 tool을 조합한 전용
tool `shareholder_commitment`(2026-07-07 신설)을 쓰면 한 번에 확인 가능 — 자사주 소각 사이클마다
**매입시점 장부가(BPS) 대비 실제 매입가**를 비교해 장부가 기준 손익까지 원화로 계산해준다(배당은 별도
"주주환원 종합" 지표로 포함).
