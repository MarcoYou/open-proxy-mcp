# 주총 안건 구조화

**주주총회 소집공고(전)와 의결 결과(후)를 안건별로 정리합니다.** 주총 전에는 무엇을 의결하는지, 주총 후에는 어떻게 처리됐는지 — 두 시점을 모두 다룹니다.

## 무엇을 답하나

- **주총 전(소집공고)**: 안건 목록(이사·감사 선임, 정관 변경, 보수한도, 재무제표 승인 등), 이사·감사 후보 약력, 보수한도 증감, 정관 변경 전/후 조문을 정리합니다.
- **주총 후(결과)**: 공시된 안건별 처리 결과를 보여줍니다. 찬반율은 수치 표를 추출할 수 있을 때만 제공하며, 요약형 공시는 결과만 있고 비율은 없을 수 있습니다. 누락 비율은 0이 아닙니다. 발행주식수 기준과 출석주식수 기준 찬성률은 분모가 다릅니다.
- 소집공고(사전)와 결과(사후)는 공시 포맷이 달라 뒤에서 다른 데이터를 씁니다 — 사용자는 "안건 보여줘" / "주총 결과" 처럼 자연어로 물으면 됩니다.
- 정기·임시주총을 모두 다룹니다. 결과 본문은 DART API 우선, KIND 대체 경로로 읽습니다. 결과를 찾지 못하면 대기·미발견으로 안내할 수 있으며 부결을 뜻하지 않습니다. 출처: 주총 소집공고·주주총회 결과 공시. 상세 → [소집공고](../../wiki/tools/shareholder_meeting_notice.md) · [결과](../../wiki/tools/shareholder_meeting_results.md).
