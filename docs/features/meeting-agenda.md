# 주총 안건 구조화

**주주총회 소집공고(전)와 의결 결과(후)를 안건별로 정리합니다.** 주총 전에는 무엇을 의결하는지, 주총 후에는 어떻게 처리됐는지 — 두 시점을 모두 다룹니다.

## 무엇을 답하나

- **주총 전(소집공고)**: 안건 목록(이사·감사 선임, 정관 변경, 보수한도, 재무제표 승인 등), 이사·감사 후보 약력, 보수한도 증감, 정관 변경 전/후 조문을 정리합니다.
- **주총 후(결과)**: 안건별 가결/부결과 찬반 비율을 보여줍니다.
- 소집공고(사전)와 결과(사후)는 공시 포맷이 달라 뒤에서 다른 데이터를 씁니다 — 사용자는 "안건 보여줘" / "주총 결과" 처럼 자연어로 물으면 됩니다.
- 출처: DART 주총 소집공고·주주총회 결과 공시. 상세 → [소집공고](../../wiki/tools/shareholder_meeting_notice.md) · [결과](../../wiki/tools/shareholder_meeting_results.md).
